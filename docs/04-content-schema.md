## 玩家状态与 Effect 概念边界

| 概念 | 用途 |
| --- | --- |
| 生命 | 当前生命事实及上限 |
| 流血 | 独立的持续状态 |
| 伤势集合 | 伤势类型、严重程度及其明确影响 |
| 感染暴露结果 | 一次接触风险的结算结果 |
| 感染进展 | 已经形成的感染程度及阶段 |
| 饱食 | 日级生存资源 |
| 状态严重程度 | 表达伤势等状态的相对级别 |
| 状态生命周期 | 状态的开始、持续和移除条件 |
| 结算层级 | 行动即时、场景行动后或每日结算 |
| 标准化 Effect | 由规则统一应用的状态变化 |

> 本节只记录概念职责，不固定最终字段名称、代码枚举、数值范围或实现 Schema。
