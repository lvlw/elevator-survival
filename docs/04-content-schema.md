# 数据配置和 Schema 设计

用途：定义数据配置格式、Schema 及其校验约束。

> 待设计

## 玩家状态与 Effect 概念边界

| 概念 | 用途 |
| --- | --- |
| 生命 | 当前生命事实及上限 |
| 流血 | 独立的持续状态 |
| 伤势集合 | 伤势类型、严重程度及其明确影响 |
| 感染暴露结果 | 一次接触风险的结算结果 |
| 感染进展 | 已经形成的感染程度及阶段 |
| 饱食 | 日级生存资源 |
| 状态严重程度 | 表达伤势等状态的相对级别 |
| 状态生命周期 | 状态的开始、持续和移除条件 |
| 结算层级 | 行动即时、场景行动后或每日结算 |
| 标准化 Effect | 由规则统一应用的状态变化 |

> 本节只记录概念职责，不固定最终字段名称、代码枚举、数值范围或实现 Schema。

## 返回与每日结算概念

| 概念 | 职责 |
| --- | --- |
| 返回结算输入 | 场景结果、携带物品、玩家状态、任务和收藏结果 |
| 返回结算输出 | 中枢状态、仓库、任务储存区、Profile 收藏和探索摘要 |
| 日结算输入 | 当前日期、玩家状态、已使用资源、任务和世界状态 |
| 日结算 Effects | 持续危险、感染、饱食、恢复、次日状态及世界变化 |
| 日结算输出 | 完整次日 Run 状态及必要 Profile 更新 |
| 结算阶段 | 返回结算、中枢整备、每日结算 |
| 结算事务状态 | 未开始、计算中、已提交或其他概念状态 |
| 结算摘要 | 向玩家展示的状态与资源变化 |

> 不固定最终字段名称和数值范围，不创建 TypeScript 类型；日结算输出必须是完整稳定状态。

## Run 终止概念

| 概念 | 职责 |
| --- | --- |
| Run 生命周期状态 | 进行中、成功、失败或放弃 |
| 终止类型 | 成功、失败或主动放弃 |
| 终止原因 | 生命归零、感染终末、期限失败、剧情失败、主动放弃或其他明确原因 |
| 终止日期 | 当前 Run 结束日期 |
| 终止前最终状态 | 用于摘要和历史的冻结状态 |
| 终止摘要 | 玩家与历史记录可见的重要结果 |
| Profile 保留变化 | 收藏、档案和历史等跨局结果 |
| 终止事务状态 | 未开始、计算中、已提交或其他概念状态 |
| 稳定恢复边界 | 异常退出时可安全恢复的位置 |
| 活动 Run 标识 | 当前是否仍存在可继续的活动 Run |

> 不固定最终字段名，不创建 TypeScript 枚举或接口，也不填写阈值、统计或评分。终止输出必须完整稳定，成功、失败和放弃只能有一个最终状态；Profile 保留变化不得包含 Run 仓库、装备、任务进度或 Run 情报。

## 场景时间行动概念

| 概念 | 说明 |
| --- | --- |
| 基础时间成本 | 行动尚未应用修正前的整数成本 |
| 时间档位 | 无、快速、普通、缓慢 |
| 时间修正 | 负重或其他明确规则提供的修正 |
| 最终时间成本 | 应用修正并向上取整后的整数 |
| 行动前剩余时间 | 行动确认前的场景时间 |
| 行动后剩余时间 | 最低为0的结果 |
| 是否越过零点 | 行动是否会耗尽剩余时间 |
| 是否触发强制返程 | 行动完成后是否立即进入返程 |
| 照明次数 | 手电筒的离散可用次数 |
| 工具耐久消耗 | 节点工程行动使用的确定成本 |

> 不固定最终字段名称，不创建 TypeScript Schema，也不填写战斗到场景时间的换算值。行动预览和实际结算必须使用同一规则来源。

## CTB 战斗状态概念

| 概念 | 说明 |
| --- | --- |
| 当前生命与生命上限 | 玩家或敌人的内部生命 |
| 相对生命阶段 | 普通 UI 展示的敌人生命状态 |
| 下次行动时间 | CTB 排序位置 |
| CTB行动时间 | 行动执行后增加的等待量 |
| 行动延后 | 对目标下次行动时间的增加 |
| 风险等级 | 无、低、中、高、极高 |
| 风险概率 | 纵向切片对应0、20、40、60、80 |
| 风险检查顺序 | 同一行动内确定性随机消耗顺序 |
| 防御状态 | 临时直接防护和伤势风险修正 |
| 流血状态 | 玩家行动后的离散生命损失 |
| 开放伤口处理状态 | 未处理或已处理 |
| 逃跑开始状态快照 | 选择逃跑时用于计算的负重档位和已存在的未处理轻度开放伤口 |
| 已计算的逃跑准备时长 | 根据开始状态快照一次性得出的本次等待量 |
| 已锁定的脱离完成时间 | 逃跑开始时生成的固定完成位置，不因普通状态变化反复计算 |
| 明确中断状态 | 失能、束缚、规则明确声明的逃跑阻断或其他经确认的中断效果 |
| 准备期间新增玩家状态 | 正常写入并在逃跑后保留，但不追溯修改当前脱离完成时间的流血、开放伤口等状态 |
| 战斗持续量 | 战斗实际经过的 CTB 时间 |
| 战斗场景时间 | 换算后写回场景的整数时间 |
| 跨遭遇敌人状态 | 生命、意图和行动循环位置 |
| 战斗临时状态 | 延后、防御和脱离准备等 |

> 不固定最终字段名称，不创建 TypeScript 类型。行动预览与结算使用同一规则来源，风险顺序必须稳定，重入不得刷新已确定战斗状态。

## 搜索、警觉与环境风险概念

| 概念 | 说明 |
| --- | --- |
| 固定搜索产出 | 每次必定揭示的结果 |
| 加权搜索池 | 一次搜索可抽取的一组候选结果 |
| 抽取次数 | 医院节点当前均为1 |
| 派生随机键 | Run、场景、节点、事件和方案构成的确定性输入 |
| 已揭示物品 | 搜索完成但未必拾取的节点物品 |
| 已拾取物品 | 已进入玩家容器的物品 |
| 场景警觉 | 未警觉或警觉 |
| 环境风险等级 | 撞门伤势或样本污染的风险 |
| 风险防护修正 | 防具对风险等级的降低 |
| 防护资源消耗 | 防护生效后产生的完整度变化 |
| 事件风险结果 | 无结果、轻度挫伤或感染暴露等 |
| 设备容量 | 手电筒最大照明次数 |
| 设备当前资源 | 当前剩余照明次数 |

> 不固定最终字段名称，不创建 TypeScript 接口或枚举。加权池必须验证总权重；搜索、事件和战斗随机源必须可独立复现；已揭示物品不能与已拾取物品或仓库物品混为同一状态。

## 世界威胁、强制返程与日结算概念

| 概念 | 说明 |
| --- | --- |
| 世界专属威胁定义 | 不同任务世界可配置不同持续威胁 |
| 暴露值 | 尚未在日结算中转化的威胁输入 |
| 内部进展值 | 威胁累积的精确整数 |
| 玩家可见阶段 | 根据阈值映射的相对状态 |
| 每日基础进展 | 当前阶段产生的自然变化 |
| 抑制效果 | 降低当日增加但不一定降低已有进展 |
| 终末阈值 | 达到后触发 Run 失败 |
| 伤势移动修正 | 轻度挫伤对移动和返程的修正 |
| 预计返程时间 | 当前状态和路线下的返程成本 |
| 强制返程损耗 | 根据预计返程时间计算的确定性生命损失 |
| 饱食当前值与上限 | 日常生存资源 |
| 饱食每日消耗 | 日结算中的固定扣除 |
| 基础恢复值 | 日结算中可受限制的生命恢复 |
| 恢复上限与修正 | 饱食、伤势、感染和流血的影响 |
| 日结算终止原因 | 生命归零、感染终末等 |
| 日结算提交状态 | 成功次日状态或终止状态 |

> 不固定最终字段名称，不创建 TypeScript 类型。感染字段不是所有世界的强制字段，医院感染实例由通用威胁定义承载；强制返程预览与结算使用同一公式，日结算不能产生可加载的中间状态。

## 医疗物品与配置版本概念

| 概念 | 说明 |
| --- | --- |
| 物品使用上下文 | 战斗、场景非战斗或中枢 |
| 上下文时间成本 | CTB时间、场景时间或0场景时间 |
| 使用条件 | 生命、状态、每日次数和目标要求 |
| 目标选择 | 一个轻度伤势等 |
| 状态持续边界 | 至下一次成功日结算等 |
| 每日使用记录 | 消毒剂等每日限制 |
| 伤势处理状态 | 未处理、已处理或已移除 |
| 自然消退条件 | 成功生成次日状态时清除 |
| 调参配置版本 | 一组可调整测试参数的版本 |
| Run绑定规则版本 | 创建 Run 时锁定的版本 |
| 规则语义 | 不应被普通数值调参改变的行为边界 |
| 测试参数 | 可通过新配置版本调整的具体数值 |

> 不固定最终字段名，不创建 TypeScript Schema。同一数值只有一个运行时权威来源，文档重复展示不代表实现复制常量；保存和回放必须包含或能够解析 Run 绑定的规则配置版本。

## 时间透支、流血检查与终局概念

| 概念 | 说明 |
| --- | --- |
| 行动开始剩余时间 | 行动确认时的场景时间 |
| 行动最终时间成本 | 所有修正后的正整数时间成本 |
| 超时债务 | 行动成本超过剩余时间的部分 |
| 预计返程时间 | 行动完成后按真实状态计算 |
| 有效紧急撤离时间 | 超时债务加预计返程时间 |
| 场景流血检查点 | 正时间非战斗行动完成后 |
| 行动主要效果 | 移动、搜索、治疗、提取等 |
| 行动后状态检查 | 流血等效果 |
| 终局优先级 | 玩家死亡优先于其他成功结果 |
| 同点事件优先级 | 已开始行动完成、玩家行动、敌人行动 |
| 原子行动结果 | 每次行动只提交一个最终结果 |

> 不固定最终字段名，不创建 TypeScript Schema。超时债务不表现为负数时间；预览与结算读取同一规则参数，回放和存档必须恢复配置版本与最终结果。
