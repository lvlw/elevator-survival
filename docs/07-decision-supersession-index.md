# 设计决策覆盖关系索引

> 本文件不是 DEC，不改变任何决策。发生冲突时仍按后续已确认 DEC 优先；本索引用于避免实现者单独读取已被后续决策局部取代的历史内容，实际权威内容仍在 `docs/05-design-decisions.md`。

## DEC-016 局部取代 DEC-015

- 被取代内容：已装备物品与背包物品均计入总重量。
- 当前有效内容：只有背包容器中的物品参与背包负重；装备栏和快捷栏物品不占背包格，也不计入背包负重。
- 取代范围：容器计重边界、UI 术语，以及装备和快捷栏是否进入负载计算。
- DEC-015 其余仍有效：格子与重量双重约束、整数重量、分档负载、有限超载及负载影响范围。

## DEC-037 局部取代 DEC-036

- 临时攻击资格只检查当前武器槽。
- 背包或仓库中的备用武器不阻止临时攻击。
- 不自动装备、交换或消耗备用武器。
- DEC-036 的其余维护和破损使用规则继续有效。

## DEC-038 局部取代 DEC-033

- 移动与返程百分比修正采用倍率相乘。
- 所有倍率应用完成后统一向上取整一次。
- 不再采用 DEC-033 中可能被理解为加法组合的表达。
- DEC-033 的其他伤势、感染和日结算规则继续有效。

## DEC-041 局部覆盖 DEC-005

- 被局部覆盖的内容：医院一日 Production Playability Milestone 当前 New Run 必须选择一个专长的要求。
- 当前有效内容：医院一日里程碑使用固定基础角色，不选择、不保存、不应用专长。
- 未被覆盖的内容：完整七日感染世界仍需从侦察、工程、生存中三选一；专长在本局内不能更换；所有专长必须能够完成主线；专长改变解决方式、风险和资源成本，而不是形成通关资格锁。
- 本索引不创造规则；权威内容来自 DEC-041。

## DEC-047 局部覆盖 DEC-028：成功时点与成功路径不追加过夜

- 被覆盖内容：只有在结束第7日后通过终局检查才能成功。
- 当前有效内容：第1至第7日，在主线与实际离开条件齐备且合法安全返回稳定中枢后，玩家可显式成功离开；不等待第7日，也不追加尚未发生的过夜。第7日成功采用同一语义。
- 保留内容：第7日正常行动与整备、无第8日自由探索、已发生硬失败优先、Run/Profile隔离、唯一原子终止及禁止回滚。普通日结算顺序不变。
- 未由本次补齐：具体主线/安装条件、未成功的末日确认与失败原因编排、正式命令/保存/界面规格。
- 适用边界：未来完整世界；原医院一日活动版本和存档不静默迁移。本索引不创造规则，权威正文见 DEC-047。

## DEC-048 对 DEC-032 的版本限定局部覆盖：一次性储备随机锚点

- 被覆盖内容：将当前 Scene 实例作为医院搜索结果的随机派生锚点之一；本次只在新完整世界明确采用的同Run一次性储备范围内局部改变。
- 当前有效内容：同一Run的一次性储备绑定Run种子、规则版本、稳定地点及来源身份，不因首次访问日期或新Scene实例重抽。敌人已消费风险序列跟随同一持续敌人，不因重入回退。
- 保留内容：原医院一日版本的派生与结果、独立子流、查询不消费随机、搜索揭示与真实拾取分离、未安全带回普通物品遗失；不因此确定新的环境事件随机锚点。
- DEC-048 对 DEC-027、DEC-031、DEC-023 的其余部分属于显式持续范围扩展或边界细化，不把它们整段废弃。DEC-040 实体权限与 DEC-045 地图知识生命周期继续有效。
- 分段突破为当前允许、Owner实际试玩待复审，不表示完整世界体验通过。本索引不创造规则，权威正文见 DEC-048。
