## 首版敌人战斗边界

> 首版一次战斗只处理一个敌人实体。敌人实体可以叙事表现为单体或被抽象为整体的小型群体，但规则层只有一个目标、一个生命状态和一组行动。

- 无多敌人目标选择；
- 无站位和距离；
- 无身体部位选择；
- 无复杂命中率、暴击或连击；
- 无元素反应或技能树；
- 具体正式敌人实例等待后续内容设计。

## 敌人静态定义模型

| 字段 | 说明 |
| --- | --- |
| ID | 稳定且唯一的敌人标识 |
| 名称 | 玩家界面显示名称 |
| 叙事形态 | 单体或抽象小型群体 |
| 类型标签 | 感染者、机械、生物或其他内容标签 |
| 生命上限 | 内部整数值，当前不填写具体数值 |
| 相对生命阶段 | 完好、受伤、重伤、濒危 |
| 防护标签 | 能够降低或处理的伤害类型 |
| 弱点标签 | 已识别后可被特定行动利用的标签 |
| 抗性或免疫 | 对控制、感染或特殊效果的边界 |
| 基础行动 | 至少一个常规行动 |
| 特殊行动 | 纵向切片至少一个具有明确意图的行动 |
| 行为条件 | 行动何时可被选择 |
| 行为权重 | 行动选择的相对权重，具体数值待设计 |
| 行动限制 | 冷却、次数、状态或资源限制 |
| 掉落或节点结果 | 战斗胜利后的内容结果，待具体敌人设计 |
| 状态 | 已确认、提议或待设计 |

## 敌人行动定义模型

| 字段 | 说明 |
| --- | --- |
| 行动ID | 稳定且唯一的行动标识 |
| 名称 | 玩家界面和意图中显示的名称 |
| 行动类别 | 基础攻击、特殊攻击、控制、防御或其他 |
| 相对速度 | 快速、普通或缓慢 |
| 意图摘要 | 玩家行动前能够看到的风险说明 |
| 直接伤害 | 相对等级，具体数值待设计 |
| 伤势风险 | 是否可能造成流血、撕裂、穿刺等 |
| 感染或污染风险 | 是否可能造成对应暴露 |
| 控制效果 | 是否可能造成失能、束缚或行动延后 |
| 目标条件 | 行动可选择的玩家状态或环境条件 |
| 使用限制 | 冷却、次数或其他限制 |
| 噪声 | 战斗或场景层记录的相对噪声 |
| 标准化 Effects | 行动结算后产生的效果集合 |
| 状态 | 已确认、提议或待设计 |

- 当前不填写具体伤害、概率、时间、持续回合或倍率。
- 高危险特殊行动必须提供可识别意图。
- 意图不能公开精确内部数值和完整未来行动序列。

## 敌人行为选择规则

- 战斗开始时，敌人需要拥有一个可展示的当前意图。
- 敌人完成行动后，为下一次行动选择并展示新意图。
- 行动选择可以读取敌人当前状态、玩家当前状态、行动条件、冷却和次数限制、行为权重及种子随机源。
- 相同初始状态、种子和玩家行动序列必须复现相同敌人行为。
- 敌人不能通过重新加载同一个未变化状态反复刷新不同意图。
- 具体行为权重和行动列表等待正式敌人设计。

## 纵向切片最小敌人内容要求

- 一个敌人实体；
- 一个基础攻击；
- 一个有明确预警的特殊攻击；
- 至少能够产生直接生命伤害；
- 特殊攻击可以额外验证伤势、感染暴露或行动控制中的至少一种；
- 具有可展示的相对生命阶段；
- 具有一个防护或弱点标签，用于验证武器差异；
- 具有确定性的行为选择；
- 胜利后能够更新节点危险状态；
- 名称、背景、具体行动名称、伤害、速度、概率和掉落保持待设计。

- 逃跑后不恢复生命，并保留公开意图与行动循环位置。
- 重入时不恢复初次遭遇的70时间，也不刷新随机结果。

### 战斗终局顺序

- 同一 CTB 时间点依次处理已开始的行动完成事件、玩家可行动事件、敌人可行动事件。
- 玩家行动主要效果后执行行动后流血，再检查玩家死亡、敌人失能和逃跑成功；玩家死亡优先于战斗胜利或逃跑。
- 敌人行动依次处理直接伤害、伤势、感染暴露和其他状态；直接伤害致死时进入 Run 失败，不再安排敌人下一行动。
- 本节不修改感染护工的生命、伤害、意图、行动循环或 CTB 参数。

### 破损武器与最低攻击可用性

- 武器耐久至少1时允许执行一次成本高于余量的合法攻击；攻击完整生效，之后耐久截断为0。
- 武器耐久0时基础攻击和签名行动不可用。
- 没有任何可用已携带武器时开放临时攻击：伤害2、CTB 140、无延后、无签名效果。
- 背包存在耐久大于0的武器时不开放临时攻击；不新增战斗中换装。
- 本节不修改感染护工生命、伤害、风险、意图顺序、CTB或警觉值。
