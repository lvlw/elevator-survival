## 隔离区防火门

- ID：`event_hospital_isolation_fire_door`
- 所属场景：`scene_blockaded_hospital_emergency_floor_1`
- 所属连线：急诊大厅 ↔ 隔离走廊
- 类型：多方案障碍
- 状态：已确认

| 方案 | 条件 | 时间 | 噪声 | 确定成本 | 结果 |
| --- | --- | ---: | --- | --- | --- |
| 使用门禁卡 | 持有实体门禁卡 | 10 | 无 | 无 | 安全开启 |
| 使用撬棍 | 装备可用撬棍 | 20 | 低 | 撬棍耐久−1 | 可控开启 |
| 使用工具箱 | 装备可用工具箱 | 30 | 低 | 工具箱耐久−1 | 开启并获得电子元件×1 |
| 使用消防斧 | 装备可用消防斧 | 10 | 高 | 消防斧耐久−1 | 暴力开启并记录高噪声 |
| 强行撞门 | 无特定装备 | 20 | 高 | 轻度伤势风险结算 | 尝试开启 |
| 放弃 | 无 | 0 | 无 | 无 | 保持封锁 |

- 工具箱回收电子元件×1为固定结果。
- 强行撞门的伤势风险和警觉结果按下方测试参数结算。
- 成功处理后，本次探索内不重复支付成本。

### 强行撞门测试参数

| 字段 | 内容 |
| --- | --- |
| 时间 | 20 |
| 噪声 | 高 |
| 场景结果 | 门打开、设置警觉 |
| 原始伤势风险 | 高，60% |
| 有效厚实外套后 | 低，20% |
| 风险成功 | 轻度挫伤 |
| 风险失败 | 无伤势 |
| 流血 | 不产生 |
| 开放伤口 | 不产生 |
| 状态 | 已确认 |

- 无论风险检查成功或失败，防火门都成功打开；风险检查只决定是否产生轻度挫伤。
- 轻度挫伤不是开放伤口，不产生流血，也不增加战斗逃跑准备时间；按 DEC-033，它在场景行动耗时层面使节点移动和返程增加10%，并在日结算层面使当日基础生命恢复减少1，且不叠加。
- 有效厚实外套只要把风险从60%降至20%，即消耗1完整度，与最终检查结果无关；同一事件最多消耗1，完整度从1降至0时本次仍有效，完整度为0时风险保持60%。
- 消防斧和强行撞门设置警觉；门禁卡、撬棍和工具箱不设置警觉。

## 感染护工遭遇

- ID：`event_hospital_infected_orderly_encounter`
- 所属场景：`scene_blockaded_hospital_emergency_floor_1`
- 所属节点：隔离走廊
- 类型：单敌人战斗
- 敌人：`enemy_infected_orderly`
- 触发：首次进入仍存在敌人的隔离走廊
- 胜利：解除走廊当前危险
- 逃跑：返回遭遇前安全节点，敌人继续存在
- 战败：进入 Run 失败
- 状态：已确认

> 医院纵向切片的敌人数值和逃跑重入规则按 DEC-031 及下方测试参数处理。

### 感染护工遭遇测试参数

- 初次进入：玩家时间0，敌人时间70，开场意图为抓挠。
- 同时间点顺序：逃跑脱离完成、玩家行动、敌人行动。
- 逃跑准备：正常80、负载80、超载110；每个未处理开放伤口追加10，最多追加20。
- 选择逃跑时，以当刻的负重档位和已经存在的未处理轻度开放伤口一次性计算准备时间，并锁定本次脱离完成时间。
- 准备期间新增的流血或开放伤口不追溯延长本次脱离完成时间，但正常写入并在成功逃跑后保留；再次开始逃跑时按新行动开始时的状态重新计算。
- 只有失能、束缚、行动规则明确声明的逃跑阻断或未来经设计决策确认的中断效果可以中断、取消或改变正在进行的脱离准备；普通直接伤害、流血和新增轻度开放伤口本身不会重新计算当前时间。
- 感染护工当前没有能够中断或重新排定脱离准备的行动；因此玩家时间0开始逃跑、敌人时间70抓挠、玩家时间80完成脱离的示例保持成立，即使抓挠产生新伤口和流血，场景时间仍为10。
- 逃跑不使用隐藏成功率，成功后返回遭遇前安全节点。
- 逃跑后保留敌人生命、公开意图、行动循环位置，以及玩家和装备已经发生的变化。
- 逃跑后清除 CTB 绝对时间、临时延后、防御和脱离准备。
- 重入时玩家时间0、敌人时间50；敌人不恢复生命，不刷新公开意图、行动循环或随机结果。
- 胜利、逃跑和战败均使用实际 CTB 经过时间换算场景时间。
- 战败不执行普通安全提取。

| 风险等级 | 概率 |
| --- | ---: |
| 无 | 0% |
| 低 | 20% |
| 中 | 40% |
| 高 | 60% |
| 极高 | 80% |

> 普通 UI 显示风险等级；检查使用战斗种子和固定顺序。

## 密封病原样本箱提取

- ID：`event_hospital_pathogen_case_retrieval`
- 所属场景：`scene_blockaded_hospital_emergency_floor_1`
- 所属节点：标本冷藏室
- 类型：任务提取互动
- 目标物品：`quest_sealed_pathogen_case`
- 状态：已确认

| 处理方式 | 时间 | 原始污染风险 | 有效厚实外套后 | 风险成功结果 |
| --- | ---: | ---: | ---: | --- |
| 谨慎检查并提取 | 30 | 低20% | 无0% | 感染暴露＋1 |
| 直接取出 | 10 | 高60% | 中40% | 感染暴露＋1 |
| 放弃提取 | 0 | 无0% | 无0% | 不提取 |

- 不要求特定装备才能取得样本箱。
- 两种成功提取方式都保证取得同一个样本箱和同一条基础来源情报；污染风险不影响提取成功。
- 污染属于表面接触和生物污染。有效厚实外套实际降低风险时消耗1完整度，同一提取最多消耗1，与检查结果无关；从1降至0时本次仍有效。
- 谨慎提取风险被有效外套降至0%时仍消耗1完整度；完整度为0时谨慎和直接提取分别保持20%和60%。
- 防毒面具不适用于本次表面接触污染；医用防护服未来可以提供更高对应防护，但不属于默认整备。
- 风险成功只记录未结算感染暴露＋1，不直接增加感染进展或改变感染阶段；暴露在日结算时按 DEC-033 转换。每次成功提取只检查一次，直接提取不会自动感染。
- 样本来源信息写入 Run 情报日志，不作为额外背包物品。
- 剩余时间大于0时可以确认越过零点完成提取，完成后立即强制返程。
- 剩余时间已经为0时不能开始提取。

> 时间归零后的强制返程按照预计返程时间确定性扣除生命；只有生还并安全返回才执行普通物品和样本箱提取。

> DEC-035 进一步规定：越过零点产生的超时债务与行动完成后的真实返程时间相加，形成有效紧急撤离时间；任务物品可以先在行动主要效果中取得，但只有通过行动后流血、生命检查和安全返回后才进入任务储存区。

## 医院事件确定性随机

- 强行撞门和样本提取分别使用独立派生随机子流，并与搜索和战斗随机子流分离。
- 撞门派生输入至少包括当前场景种子、`event_hospital_isolation_fire_door`、强行撞门方案 ID 和事件执行序号。
- 提取派生输入至少包括当前场景种子、`event_hospital_pathogen_case_retrieval`、提取方式 ID 和事件执行序号。
- 这些成功事件在医院纵向切片中只能完成一次，正常执行序号固定稳定；不同事件和方案不得共享可变全局随机游标。
- 搜索顺序、战斗行动和风险检查次数、查看 UI、重新加载或离开再返回，都不能改变已经确定的事件结果。
- 行动完整提交前异常退出时恢复至稳定事务边界；相同种子、状态和操作必须复现相同结果，失败后重载不得重新抽取。

## 医疗准备与日结算边界

- 消毒剂减少未结算感染暴露，感染抑制剂减少当日感染增加；两者作用层级不同，可以同日使用。
- 轻度挫伤和已处理轻度开放伤口只在成功日结算生成次日状态时自然移除；未处理开放伤口保留。
- 日结算中途失败时不生成次日状态，也不执行轻伤自然移除或镇痛的普通到期清理。
- 中枢医疗不提供免费治疗；物品使用必须消耗实际库存，原子应用效果并形成新的自动保存稳定边界。
- 玩家确认结束本日前应预览流血、感染、饱食、恢复、轻伤自然消退、镇痛修正及失败风险；确认后不能插入新的医疗操作。

## 场景行动终局边界

```text
行动主要效果
→ 行动后流血
→ 玩家死亡检查
→ 成功、返程或失败结果
```

- 行动后死亡时不安全返回、不提取任务物品，也不进入中枢。
- 强制返程、生还提取和失败保持互斥并原子提交。

## 中枢维护与工具事件边界

- 基础维护工时每日只生成一次3点，不因重复进入中枢界面而重复生成，且未用部分不跨日；维修须消耗实际库存或当日工时，分配与消耗原子提交。
- 材料维修量须在本次操作内分配；确认结束本日后不能维修或充能。
- 工具耐久0时对应选项不可用；撬棍损坏后医院仍有门禁卡、工具箱、消防斧和强行撞门路线。
- 工具箱维修需金属零件1和电子元件1，仅靠防火门固定获得的电子元件不能完成维修。
