## 隔离区防火门

- ID：`event_hospital_isolation_fire_door`
- 所属场景：`scene_blockaded_hospital_emergency_floor_1`
- 所属连线：急诊大厅 ↔ 隔离走廊
- 类型：多方案障碍
- 状态：已确认

| 方案 | 条件 | 相对耗时 | 噪声 | 主要结果 |
| --- | --- | --- | --- | --- |
| 使用门禁卡 | 持有隔离区门禁卡 | 快速 | 无 | 安全开启 |
| 使用撬棍 | 装备撬棍 | 普通 | 低 | 可控开启并消耗耐久 |
| 使用工具箱 | 装备工具箱 | 缓慢 | 低 | 绕过门禁，可能保留或回收电子元件 |
| 使用消防斧 | 装备消防斧 | 快速 | 高 | 暴力破门，可能提高敌人警觉 |
| 强行撞门 | 无特定装备 | 普通 | 高 | 存在伤势风险 |
| 放弃 | 无 | 无 | 无 | 保持封锁 |

> 本轮不填写耐久、材料、伤势概率或具体时间。

## 密封病原样本箱提取

- ID：`event_hospital_pathogen_case_retrieval`
- 所属场景：`scene_blockaded_hospital_emergency_floor_1`
- 所属节点：标本冷藏室
- 类型：任务提取互动
- 目标物品：`quest_sealed_pathogen_case`
- 状态：已确认

| 处理方式 | 相对耗时 | 污染风险 | 结果 |
| --- | --- | --- | --- |
| 谨慎检查并提取 | 较高 | 较低 | 取得样本箱并获得来源情报 |
| 直接取出 | 较低 | 较高 | 取得样本箱并承担更高暴露风险 |
| 放弃提取 | 无 | 无 | 不取得样本箱 |

- 不要求特定装备才能取得样本箱。
- 医用防护服、防毒面具、消毒剂或专长未来可以改变风险，但本轮不填写具体修正。
- 样本来源信息写入 Run 情报日志，不作为额外背包物品。
