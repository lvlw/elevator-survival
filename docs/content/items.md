## 武器统一属性模型

首版武器至少需要记录以下字段：

| 字段 | 说明 |
| --- | --- |
| ID | 稳定且唯一的数据标识 |
| 名称 | 玩家界面显示名称 |
| 分类 | 武器 |
| 格子尺寸 | 武器作为备用物品放进背包时的占格 |
| 重量 | 武器作为备用物品放进背包时的背包负重 |
| 可旋转 | 是否允许在背包中旋转90度 |
| 装备槽位 | 武器位 |
| 伤害类型 | 切割、穿刺、钝击、电击等 |
| 伤害等级 | 低、中、高等相对标尺 |
| 行动速度 | 快速、普通、缓慢 |
| 噪声等级 | 低、中、高 |
| 控制能力 | 无、弱、中、强 |
| 基础行动 | 武器默认提供的战斗行动 |
| 标志性行动 | 武器独有的第二个主要战斗行动 |
| 探索用途 | 武器能够处理的有限场景障碍 |
| 探索标签 | 用于节点条件匹配的标签 |
| 消耗方式 | 耐久、电量或其他消耗 |
| 主要优势 | 武器最擅长解决的问题 |
| 主要代价 | 使用武器需要承担的成本 |
| 弱点 | 不适合处理的敌人或场景 |
| 获取场景 | 主要获取来源，未确认时填写“待设计” |
| 状态 | 已确认、提议或待设计 |

- 当前不填写具体伤害数值、行动时间、眩晕概率、耐久上限和电量容量。
- 这些数值等待最小战斗模型确定后再补充。
- 武器当前装备在武器位时不占用背包格子，也不计入背包负重；武器作为备用物品放入背包时，按照其格子尺寸和重量正常计算。
- 防具和实用装备遵循相同的容器规则：当前装备时不占用背包格子，也不计入背包负重；作为备用物品放入背包时正常占格并计算背包负重。

## 武器与工具的边界

> 武器可以通过暴力或简单动作解决少量场景障碍，但专用工具应当提供更安静、更低风险、更低耗时、更低耐久消耗或更高资源保留率的解决方案。武器不得完整替代实用装备位。

| 障碍 | 消防斧 | 金属管 | 撬棍 | 工程专长＋工具箱 |
| --- | --- | --- | --- | --- |
| 木板封门 | 快速破坏，但噪声高，可能损坏内部物资 | 可以破坏，但耗时和耐久成本更高 | 较安静地拆除，并可能保留材料 | 精确拆解，成本更低，并可能获得额外材料 |

> 此处仅用于说明武器与工具的设计边界，不代表撬棍和工具箱的最终属性已经确认。

## 防具风险处理示例

> 防具提供的是更安全、更低风险或更低资源消耗的处理方式，而不是进入主线区域的唯一资格。

| 高污染区域处理方式 | 预期结果 |
| --- | --- |
| 穿戴医用防护服 | 以较低感染暴露风险进入 |
| 使用消毒用品并缩短停留 | 消耗资源，承担中等剩余风险 |
| 使用生存专长相关选项 | 降低暴露成本或获得替代处理方式 |
| 修复通风、隔离或净化设施 | 改变场景状态后进入 |
| 强行进入 | 不消耗前置资源，但承担较高感染风险 |

> 具体成本、概率和效果等待节点探索及事件系统确定。本表只确认医用防护服不能成为首版主线资格锁。

## 实用装备统一属性模型

> 首版装备栏设置一个实用装备位，用于装备手持工具、照明设备、探测设备或穿戴式功能设备。当前装备在实用装备位中的物品不占背包格子，也不计入背包负重；作为备用物品放入背包时，按照尺寸和重量正常计算。

| 字段 | 说明 |
| --- | --- |
| ID | 稳定且唯一的数据标识 |
| 名称 | 玩家界面显示名称 |
| 分类 | 工具或实用装备 |
| 格子尺寸 | 作为备用物品放入背包时的占格 |
| 重量 | 作为备用物品放入背包时的背包负重 |
| 可旋转 | 是否允许在背包中旋转90度 |
| 装备槽位 | 实用装备位 |
| 主要能力标签 | 用于节点、事件和环境风险匹配 |
| 主要用途 | 该装备最核心的解决能力 |
| 次要用途 | 次级或情境性能力 |
| 操作耗时 | 快速、普通或缓慢等相对标尺 |
| 噪声等级 | 无、低、中或高等相对标尺 |
| 消耗方式 | 耐久、电池、电量、滤芯或其他资源 |
| 专长协同 | 与侦察、工程或生存专长的组合方式 |
| 无法处理 | 明确不能解决的障碍或风险 |
| 战斗可用性 | 能否在战斗中使用及其大致用途 |
| 主要优势 | 最擅长处理的问题 |
| 主要代价 | 装备或使用时承担的成本 |

## 消耗品统一属性模型

> 首版消耗品使用一个完整单位执行一次主要效果，不保存部分剂量。设备补给品沿用消耗品的堆叠和消耗规则，但不能直接对角色使用。

| 字段 | 说明 |
| --- | --- |
| ID | 稳定且唯一的数据标识 |
| 名称 | 玩家界面显示名称 |
| 分类 | 医疗品、生存补给或设备补给品 |
| 格子尺寸 | 放入背包时占用的格子 |
| 单件重量 | 每一个物品单位产生的背包负重 |
| 可旋转 | 是否允许旋转90度 |
| 可堆叠 | 是否允许与相同状态物品堆叠 |
| 堆叠上限 | 单个背包格中允许保存的最大数量 |
| 快捷栏资格 | 是否允许放入快捷栏 |
| 战斗可用性 | 是否允许在战斗中使用 |
| 使用目标 | 角色、伤口或兼容设备 |
| 主要用途 | 该物品最主要解决的问题 |
| 次要用途 | 最多一个附加用途，没有则填写“无” |
| 不负责处理 | 明确不能解决的问题 |
| 消耗方式 | 使用后消耗一个完整单位 |
| 获取场景 | 未确认时填写“待设计” |
| 状态 | 已确认、提议或待设计 |

- 当前不填写具体恢复量、作用时间、行动时间、概率、设备容量和补充数值。
- 堆叠总重量按照“单件重量×当前数量”计算。
- 快捷栏中只能放置一个实际物品单位。
- 设备补给品不能直接对角色使用。

| 止痛药 | 暂时压制部分伤势惩罚 | 治疗伤势、停止流血、降低感染 |
| 压缩口粮 | 恢复饱食 | 生命、伤势、感染 |
| 感染抑制剂 | 降低感染进展或延缓恶化 | 完全治愈感染、处理直接伤势 |

- 生命恢复不自动停止流血，也不自动治疗伤势。
- 消毒剂主要作用于暴露和污染伤口阶段。
- 感染抑制剂主要作用于已形成的感染进展。
- 止痛药效果结束后原伤势仍然存在。
- 急救包可处理的轻度伤势范围仍待伤势内容确定。
- 当前不填写具体恢复量、持续时间、阶段变化或概率。

## 拆解规则

- 首版可以允许损坏或不需要的装备拆解为少量制作材料。
- 拆解返还必须低于物品的制作或完整维修成本。
- 不允许无损拆解。
- 不允许形成制作后拆解的资源增殖循环。
- 普通消耗品默认不能拆解。
- 任务物品不能自由拆解。
- 具体拆解返还种类和数量等待资源经济设计后确定。
