## 武器统一属性模型

首版武器至少需要记录以下字段：

| 字段 | 说明 |
| --- | --- |
| ID | 稳定且唯一的数据标识 |
| 名称 | 玩家界面显示名称 |
| 分类 | 武器 |
| 格子尺寸 | 武器作为备用物品放进背包时的占格 |
| 重量 | 武器作为备用物品放进背包时的背包负重 |
| 可旋转 | 是否允许在背包中旋转90度 |
| 装备槽位 | 武器位 |
| 伤害类型 | 切割、穿刺、钝击、电击等 |
| 伤害等级 | 低、中、高等相对标尺 |
| 行动速度 | 快速、普通、缓慢 |
| 噪声等级 | 低、中、高 |
| 控制能力 | 无、弱、中、强 |
| 基础行动 | 武器默认提供的战斗行动 |
| 标志性行动 | 武器独有的第二个主要战斗行动 |
| 探索用途 | 武器能够处理的有限场景障碍 |
| 探索标签 | 用于节点条件匹配的标签 |
| 消耗方式 | 耐久、电量或其他消耗 |
| 主要优势 | 武器最擅长解决的问题 |
| 主要代价 | 使用武器需要承担的成本 |
| 弱点 | 不适合处理的敌人或场景 |
| 获取场景 | 主要获取来源，未确认时填写“待设计” |
| 状态 | 已确认、提议或待设计 |

- 当前不填写具体伤害数值、行动时间、眩晕概率、耐久上限和电量容量。
- 这些数值等待最小战斗模型确定后再补充。
- 武器当前装备在武器位时不占用背包格子，也不计入背包负重；武器作为备用物品放入背包时，按照其格子尺寸和重量正常计算。
- 防具和工具遵循相同的容器规则：当前装备时不占用背包格子，也不计入背包负重；作为备用物品放入背包时正常占格并计算背包负重。

## 武器与工具的边界

> 武器可以通过暴力或简单动作解决少量场景障碍，但专用工具应当提供更安静、更低风险、更低耗时、更低耐久消耗或更高资源保留率的解决方案。武器不得完整替代工具槽。

| 障碍 | 消防斧 | 金属管 | 撬棍 | 工程专长＋工具箱 |
| --- | --- | --- | --- | --- |
| 木板封门 | 快速破坏，但噪声高，可能损坏内部物资 | 可以破坏，但耗时和耐久成本更高 | 较安静地拆除，并可能保留材料 | 精确拆解，成本更低，并可能获得额外材料 |

> 此处仅用于说明武器与工具的设计边界，不代表撬棍和工具箱的最终属性已经确认。

## 防具统一属性模型

> 首版防具不使用单一防御力。直接防护、伤势防护和感染防护需要分别记录。当前装备在防具位中的防具不占背包格子，也不计入背包负重；防具作为备用物品放入背包时，按照其格子尺寸和重量正常计算。

| 字段 | 说明 |
| --- | --- |
| ID | 稳定且唯一的数据标识 |
| 名称 | 玩家界面显示名称 |
| 分类 | 防具 |
| 格子尺寸 | 作为备用防具放进背包时的占格 |
| 重量 | 作为备用防具放进背包时的背包负重 |
| 可旋转 | 是否允许在背包中旋转90度 |
| 装备槽位 | 防具位 |
| 直接防护 | 对生命伤害的相对防护等级 |
| 伤势防护 | 对流血、撕裂、穿刺伤等伤势的相对防护等级 |
| 感染防护 | 对生物污染和感染暴露的相对防护等级 |
| 行动负担 | 防具穿戴后产生的固定行动代价 |
| 防护标签 | 防具能够处理的攻击或环境类型 |
| 探索用途 | 防具能够降低风险的节点或事件类型 |
| 探索标签 | 用于节点条件和效果匹配的标签 |
| 损耗方式 | 完整度、耐久或其他损耗 |
| 主要优势 | 防具最擅长处理的问题 |
| 主要代价 | 穿戴该防具需要承担的成本 |
| 弱点 | 防具不适合处理的风险 |
| 获取场景 | 主要获取来源，未确认时填写“待设计” |
| 状态 | 已确认、提议或待设计 |

- 当前不填写具体减伤比例、伤势抵抗概率、感染抵抗概率、行动耗时倍率、完整度上限和维修成本。
- 以上数值等待节点探索规则和最小战斗模型确定后再补充。
- 防护相对等级使用：无 / 低 / 中 / 高。
- 行动负担相对等级使用：无 / 低 / 中。

## 防具风险处理示例

> 防具提供的是更安全、更低风险或更低资源消耗的处理方式，而不是进入主线区域的唯一资格。

| 高污染区域处理方式 | 预期结果 |
| --- | --- |
| 穿戴医用防护服 | 以较低感染暴露风险进入 |
| 使用消毒用品并缩短停留 | 消耗资源，承担中等剩余风险 |
| 使用生存专长相关选项 | 降低暴露成本或获得替代处理方式 |
| 修复通风、隔离或净化设施 | 改变场景状态后进入 |
| 强行进入 | 不消耗前置资源，但承担较高感染风险 |

> 具体成本、概率和效果等待节点探索及事件系统确定。本表只确认医用防护服不能成为首版主线资格锁。
