## 场景探索时间模型

> 首版场景使用整数离散时间。时间只在移动、搜索、障碍处理、工程、战斗、特定物品使用、事件选项和返程等有意义行为中结算，不使用持续运行的现实倒计时。

| 字段 | 说明 |
| --- | --- |
| 场景初始时间 | 玩家进入场景时拥有的离散时间单位 |
| 当前剩余时间 | 本次探索尚可使用的时间 |
| 入口节点 | 连接电梯并用于计算返程的节点 |
| 当前节点 | 玩家当前所在位置 |
| 预计返程成本 | 根据当前已知可通行网络和玩家状态计算 |
| 返程后预计剩余 | 当前剩余时间减去预计返程成本 |
| 时间警告状态 | 安全、接近返程界限、预计超时或强制返程 |
| 强制返程状态 | 是否已经进入时间耗尽后的返程阶段 |

- 当前不填写所有场景共用的固定初始时间。
- 当前不填写统一移动、搜索或返程数值。
- 数值由纵向切片具体场景测试确定。

## 主动撤离与强制返程

- 非战斗状态下，只要存在已知可通行路线，玩家可以主动撤离。
- UI持续显示剩余时间、预计返程成本和返程后预计剩余时间。
- 剩余时间低于预计返程成本时，显示明显超时警告。
- 玩家可以忽略警告并继续行动。
- 剩余时间降至0后，不立即死亡或判定 Run 失败。
- 时间归零后进入强制返程：
  - 禁止新的普通搜索；
  - 禁止新的非必要工程；
  - 按当前路线和玩家状态进行返程结算；
  - 按 DEC-033 确定性计算生命损耗。
- 医院纵向切片的具体强制返程规则见下方；其他世界中无有效返程路线等边界仍待设计。
- 玩家未搜完场景不会因主动撤离本身自动受到评分惩罚。

## 返回电梯后的阶段边界

| 阶段 | 是否推进日期 | 是否消耗场景探索时间 | 主要职责 |
| --- | --- | --- | --- |
| 返回电梯结算 | 否 | 否，返程时间此前已经结算 | 提取物品、更新任务、生成摘要并自动保存 |
| 电梯中枢整备 | 否 | 否 | 治疗、补给、制作、维修、拆解、整理和查看档案 |
| 每日结算 | 是，结算完成后推进 | 否 | 处理日级状态、生成次日状态和更新世界 |

- 场景系统在玩家安全回到入口并完成返程结果后结束本次探索，不自动开始下一日。
- 场景撤离结果作为返回结算输入，返回结算完成后才进入中枢整备。
- 中枢整备不能重新打开已经结束的当日场景。
- 普通临时场景状态默认不跨日；明确声明的任务或世界状态可以在日结算后跨日更新。

### 负重移动测试值

| 背包状态 | 修正 | 基础10移动的实际成本 |
| --- | ---: | ---: |
| 正常 | ×1.00 | 10 |
| 负载 | ×1.10 | 11 |
| 超载 | ×1.25 | 13 |

- 最终成本向上取整，单次移动只进行一次最终取整。
- 返回估算使用当前负重和已知可通行路线。
- 搜索和门禁互动不默认应用负重修正。

#### 轻度挫伤移动修正

| 状态 | 移动修正 |
| --- | ---: |
| 无轻度挫伤 | 0% |
| 轻度挫伤 | +10% |

| 负重状态 | 无轻度挫伤 | 有轻度挫伤 |
| --- | ---: | ---: |
| 正常 | 10 | 11 |
| 负载 | 11 | 12 |
| 超载 | 13 | 14 |

- 负重与轻度挫伤修正加法组合：`ceil（基础移动成本 ×（1＋负重修正＋伤势修正））`。
- 单次移动或返程边只进行一次最终向上取整。
- 在场景行动耗时层面，轻度挫伤只影响节点移动与返程，修正为+10%；不影响战斗 CTB、防火门、主要搜索、样本提取、战斗逃跑准备、UI 或背包整理。在日结算层面，它仍属于未处理轻度伤势，使当日基础生命恢复减少1。
- 医院纵向切片中轻度挫伤不叠加；轻度开放伤口不增加节点移动或返程时间。

#### 搜索随机与已揭示物品

- 搜索采用固定产出加一次节点独立种子抽取；保安值班室仅使用固定产出。
- 搜索结果在逻辑上由场景实例创建时确定；允许使用相同派生种子延迟物化，但结果不能受搜索顺序、战斗随机消耗、手电筒、重载或重复进入影响。

- 未拾取物品在本次探索内留在节点，返回时不刷新或增量抽取；无法装入背包的物品不会消失、进入仓库、传送至电梯或替换已有物品。
- 探索结束时未安全带回的普通物品丢失；门禁卡、任务物品和情报按各自特殊对象规则处理。
- 已揭示物品与已拾取物品、玩家已知信息与节点真实状态分别记录。

### 时间不足行动

- 剩余时间大于0时，允许确认并执行成本超过剩余时间的合法行动。
- 行动完整结算后，剩余时间最低截断为0，并按 DEC-035 将超出部分记录为超时债务后进入强制返程。
- 剩余时间为0时不能开始新的普通搜索、可选互动、非必要工程或任务提取。
- 一次探索最多只有一个越过零点的普通行动；玩家可以主动用生命与恢复空间换取额外行动收益，但必须看到超时与死亡风险预览。
- 强制返程按下方确定性规则结算。

### 医院强制返程测试值

```text
超时债务
= max（0，行动最终时间成本－行动开始时剩余时间）

有效紧急撤离时间
= 超时债务＋行动完成后的预计返程时间

基础损耗
= min（4，ceil（有效紧急撤离时间 ÷ 20））
```

- DEC-035 作为后续决策，只覆盖越过零点后的超时处理；无超时债务时，DEC-033 的既有示例和结果保持不变。
- 行动确认时锁定开始剩余时间、最终成本和预计债务；行动完成后按真实节点、物品、负重、挫伤、镇痛、路线、生命和流血计算返程部分，债务不因后续状态变化重算。
- 有效紧急撤离时间为0时基础损耗和流血追加均为0；否则每20产生1点基础损耗、封顶4，流血额外损失1且不计入基础上限，理论总损耗最高5。
- 损耗一次性应用，不视为攻击，不应用防御或厚实外套减伤，也不执行随机判定。
- 生还后正常安全提取；生命归零则按 DEC-028 进入 Run 失败且不执行安全提取。
- 返程中不能改路线、搜索、互动、战斗或使用快捷物品；不随机丢物、不产生新随机伤势或暴露、不消耗额外装备资源，场景时间不记负数。
- 强制返程原子提交，不保存部分扣血但尚未完成提取或失败判定的状态。
- 到达电梯前室且债务和返程时间均为0时直接安全返回、损耗0；位于前室但存在债务时，仍按债务计算损耗。
