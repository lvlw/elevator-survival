## 场景探索时间模型

> 首版场景使用整数离散时间。时间只在移动、搜索、障碍处理、工程、战斗、特定物品使用、事件选项和返程等有意义行为中结算，不使用持续运行的现实倒计时。

| 字段 | 说明 |
| --- | --- |
| 场景初始时间 | 玩家进入场景时拥有的离散时间单位 |
| 当前剩余时间 | 本次探索尚可使用的时间 |
| 入口节点 | 连接电梯并用于计算返程的节点 |
| 当前节点 | 玩家当前所在位置 |
| 预计返程成本 | 根据当前已知可通行网络和玩家状态计算 |
| 返程后预计剩余 | 当前剩余时间减去预计返程成本 |
| 时间警告状态 | 安全、接近返程界限、预计超时或强制返程 |
| 强制返程状态 | 是否已经进入时间耗尽后的返程阶段 |

- 当前不填写所有场景共用的固定初始时间。
- 当前不填写统一移动、搜索或返程数值。
- 数值由纵向切片具体场景测试确定。

## 节点运行状态

| 字段 | 说明 |
| --- | --- |
| 是否发现 | 节点是否已经出现在玩家地图中 |
| 是否到达 | 玩家是否曾经进入该节点 |
| 是否已搜索 | 主要搜索是否已经完成 |
| 障碍状态 | 未处理、已绕过、已解除或已破坏等 |
| 当前连线状态 | 可通行、封锁、隐藏或已开启 |
| 已揭示物资 | 玩家已经知道存在的物品 |
| 剩余物资 | 尚未取走或仍留在节点的物品 |
| 已知危险 | 玩家当前已经确认的风险 |
| 已触发事件 | 本次探索中已经发生的节点事件 |
| 玩家丢弃物品 | 玩家主动留在节点的普通物品 |
| 暂存任务物品 | 玩家暂时放下且尚未撤离的任务物品 |
| 设施状态 | 供电、通风、门禁、污染等状态 |

> 静态节点定义与本次探索运行状态必须分开。玩家离开并返回节点时，运行状态不能重新生成。

## 节点连线模型

| 字段 | 说明 |
| --- | --- |
| 起点节点 | 连线出发节点 |
| 终点节点 | 连线到达节点 |
| 是否双向 | 是否可以双向移动 |
| 基础移动成本 | 未受状态影响时的离散时间成本 |
| 可见条件 | 玩家何时知道该路线存在 |
| 通行条件 | 路线当前是否允许通过 |
| 封锁原因 | 障碍、敌人、场景状态或任务阶段 |
| 状态变化 | 工程、事件或任务是否能开启或关闭路线 |

- 预计返程只使用玩家当前已知且可通行的路线。
- 返程目标为电梯入口节点。
- 返程成本需要应用背包负重、伤势及其他移动效果。
- 未发现的隐藏路线不能提前参与UI估算。

| 信息或内容 | 到达时表层观察 | 完成主要搜索后 |
| --- | --- | --- |
| 节点名称和基础描述 | 是 | 是 |

| 明显障碍和危险 | 是 | 是 |

| 隐藏物资 | 否 | 可能揭示 |

- 独立互动不重新开放节点通用搜索。

## 主动撤离与强制返程

- 非战斗状态下，只要存在已知可通行路线，玩家可以主动撤离。
- UI持续显示剩余时间、预计返程成本和返程后预计剩余时间。
- 剩余时间低于预计返程成本时，显示明显超时警告。
- 玩家可以忽略警告并继续行动。
- 剩余时间降至0后，不立即死亡或判定 Run 失败。
- 时间归零后进入强制返程：
  - 禁止新的普通搜索；
  - 禁止新的非必要工程；
  - 按当前路线和玩家状态进行返程结算；
  - 可以产生额外风险或代价。
- 具体强制返程惩罚等待纵向切片测试确定。
- 玩家未搜完场景不会因主动撤离本身自动受到评分惩罚。

| 提高追击或遭遇风险 | 待设计 |

## 返回电梯后的阶段边界

| 阶段 | 是否推进日期 | 是否消耗场景探索时间 | 主要职责 |
| --- | --- | --- | --- |
| 返回电梯结算 | 否 | 否，返程时间此前已经结算 | 提取物品、更新任务、生成摘要并自动保存 |
| 电梯中枢整备 | 否 | 否 | 治疗、补给、制作、维修、拆解、整理和查看档案 |
| 每日结算 | 是，结算完成后推进 | 否 | 处理日级状态、生成次日状态和更新世界 |

- 场景系统在玩家安全回到入口并完成返程结果后结束本次探索，不自动开始下一日。
- 场景撤离结果作为返回结算输入，返回结算完成后才进入中枢整备。
- 中枢整备不能重新打开已经结束的当日场景。
- 普通临时场景状态默认不跨日；明确声明的任务或世界状态可以在日结算后跨日更新。
