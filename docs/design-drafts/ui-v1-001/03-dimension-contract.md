宽方程为2M+L+C+R+2G；高方程为2M+HUD+B+F+2G。格位严格6×4、间距4；跨格框包含内部间距。数量与资源条属于组件，不烘焙进物品图。装备／背包切换，两个快捷位归入固定携带区；低高度时整栏局部滚动可达，不堆叠全部装备与背包。

R2普通面板按内容分档：短内容640、详情680、摘要800、参数880、复杂整理1000、地图1040 CSS宽，受中央可用宽限制；高度随内容并封顶，最大态C×B。战斗仍使用min(1080,C−2I)×min(780,B−2I)，I为16或12。战斗在低档直接最大态。竞技区从面板扣除内距、四个固定行和四个间距，五档应为452/412/444/364/328。边线采用outline，避免border额外吃掉2像素。实际测量与允许局部滚动见[响应式结果](validation/responsive-results.json)。

人物使用1536×1920的**呈现画布**，不是宣称原PNG有该分辨率。原PNG尺寸、平移、比例、脚点(0.50,0.92)、命中锚、允许9px/−3px/2°短时位移见[锚点清单](spec/registered-art.json)。不会逐阶段trim透明边缘。FX放在同一主体容器，以命中锚百分比定位；舞台缩放只重算容器。

背景逐槽cover：s=max(槽宽/源宽,槽高/源高)，可见源区=(槽宽/s,槽高/s)。偏移=(源尺寸−可见尺寸)×focal。全部24节点×五桌面档的真实计算、focal和遮挡预算见[裁切清单](spec/node-crop-manifest.json)。不同房间共享建筑底板时用具名焦点变体，不宣称额外生成了24张独立原画。

背景大多为1672×941，1920档1200×888舞台所需DPR2约为2400×1776可见像素；原生像素不足。**DPR2背景项未通过**。没有插值放大或把参考1672图标为4K。高分辨率再生产是明确交付缺口，当前稿可供布局与美术方向审阅，不可宣称高清生产验收。

512图标在详情限制256 CSS；新1254图标详情最大512。alpha原件保留；部分新图边距小于建议12.5%，contain与容器留白缓解，不谎报源安全边距。8:5近景槽独立；供电原图2006×784按槽裁切，重点柜体需在实际预览中核对。九宫格源切边48px对应CSS角24px，中心与边可拉伸，角不按整面板放大。

输出PNG为CSS 1×实际浏览器DOM绘制，源分辨率与DPR2供给单独核对。SVG为可编辑HTML组件序列化，带独立相对素材，不是Figma原生文件；HTML/CSS是完整可编辑母版。字体使用系统微软雅黑／苹方／sans-serif，不分发字体文件。
