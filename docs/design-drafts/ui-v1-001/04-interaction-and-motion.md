# 点击、参数与战斗演出

[实际原型](prototype/index.html)按离线文件组织（file协议实开未核验）；本地作者导出服务只用于写本目录图稿，不是游戏服务。原型无生产入口、引擎导入、Storage、真实随机或持久化。设计状态索引可独立打开每张变体。

L0保持短说明和目标常驻；Tab聚焦不自动弹大层。L1完整普通操作不追加通用确认。L2显式方法、材料、数量、伤口、格位、旋转及机械总池分配；缺参时禁用或就地解释。L3仅显示当前正式适用的返回终局、关键物留置和必死保护。取消不结算，参数失效不无声替换实例。

中央查看、还原／放大、地图、物品详情均为呈现。地图没有移动点击。跨图只演示H0医院前室与T0酒店入口的真实相邻关系；其余场景方向只示意单边请求，不运行路线系统。战斗没有收起或Escape退出；合法退却是独立行动样例。信息层返回战斗不推进CTB。

格位不是拖着图就算成功：2×2目标高亮四格，越界／占用显示无效。普通物移动、拆分、合并与快捷迁移单独表达请求；原型不搬动生产实物。旋转图示见P10，保持图像比例。其余表单只演示参数与反馈，不宣称完成所有核心资格验证。

战斗图层：背景→透明玩家／敌人→主体锚定FX→公开阶段和当前意图→相对顺序→行动条。原型动作按钮播放已结事件**示意**；700ms整段时间和约200ms命中是表现候选。阶段图切换不产生伤害。决策点无自行推进计时器；查看帮助、放大和减少动态不重放动作。减少动态取消位移、保留结果文本和静态阶段。

当前安全DTO不足以提供连续CTB位置／速度与完整敌人展示映射。原型“你／敌”位置、移动速度和阶段变化是明确设计模拟，不是未来队列或实际战斗计算。生产应从已提交公开事件消费演出，不能用动画回调发奖、扣血、保存或确定死亡。接口草案见[交接](06-implementation-handoff-draft.md)。

保存异常始终区分“已生效、未保存”：只保存重试不回滚、不重放原动作；失锁／坏档／读取失败／展示不可用不补发初始物、不清档。R1实际点击证据与未完成项见[交互记录](validation/r1/edge-browser.json)。

R1将设计索引的独立样例与查看栈分开。初选确认到H0保留配装/专长；帮助、地图和详情保持当前身体/实物/终局，不载入另一健康样例。样本不可拆，移动/留置/药食绑定所点对象。护工、装卸工、技术员分别退至H1、L1、C1；未运行移动或战斗结算。

采样展示谨慎10/直接6基础精力及参与护具请求1、实际1的完整度变化；最后一点、破损和未装备另列对照。不揭露概率/答案。防御只演示姿态，通用FX明确不推进战损；攻击才切换作者编排阶段。三者均不计算真实伤害或消费生产物品。

R2增加内容区键盘焦点，长内容可用End/PageDown滚动；放大/还原后焦点留在对应工具按钮。失效的明确objectRef直接失效，不回退到同名对象；终局放大只改展示。源码30项检查与实际Edge交互分别记录，不累计为生产测试。
