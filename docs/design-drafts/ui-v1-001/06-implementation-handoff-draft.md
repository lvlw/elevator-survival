# 后续实现交接草案

本稿仅供主线与Owner审阅，**未授权下一工程**。本次没有修改生产UI、规则、Schema、保存、依赖、CI或已批合同。先联合审阅准确SHA及完整图稿，再另行形成工程任务；不自动落地。

可复用呈现设计：五档壳token、中央普通／最大层、6×4格位、真实快捷槽、装备切换、只读知识图、参数表单、四终局和保存异常。组件须从安全查询取得公开事实；不能把本原型的样例数组、定值、屏幕ID、asset ID或注册画布写成生产存档结构。

| 唯一职责 | 接入要求 | 禁止 |
| --- | --- | --- |
| 现有纯核心 | 命令资格、成本、随机、身体、物品与任务结算 | React或动画再计算 |
| session／application | 原子提交、使用权、保存与恢复、参数过期 | 展示层另持一份可变真相 |
| 安全查询 | 当前公开信息、合法请求预览、有限知识 | 读取完整存档或敌私有HP |
| React呈现 | 标签、容器、焦点、图层、只读动画消费 | 以图像名称／地点猜当前敌身份 |
| 资产目录 | 内容到呈现候选的受审映射与尺寸 | 注册新委托、道具或玩家入口 |

缺口A：最小公开敌人呈现键候选。只用于已进入的当前遭遇，返回受审展示组（名称／三敌阶段资产组）；不暴露definition/instance私有字段、精确HP、来源或未来敌人。键失配应安全降级并报告，不能猜地点补图。本任务未修改DTO。

缺口B：公开已提交演出事件候选。需要可去重的公开事件标识、已允许的行动先后、主体呈现引用、公开阶段前后变化、可跳过演出顺序及明确决策停点。若不批准连续位置数据，只动画真实已知先后；不得以系统时间推算敌人未来回合。恢复到最新已结状态不重放结算；跳过与减少动态保持同一结果。具体字段与披露审计由后续精确工程契约决定，本稿不创建保存格式。

目标摘要／地图继续依现有安全来源；缺字段列接口缺口，不读取全图。NPC仅接林岑一次交换与周衡方法调查。新的视觉造型不构成新玩法采纳。

后续工程验收至少包括真实状态切换、键盘焦点、敌人映射完整性、DPR2高清资产替换、缩放与触达、只保存重试、恢复不重演和减少动态。本轮原型与静态导出不能代替生产集成测试。当前生产test/typecheck/build均NOT RUN。
