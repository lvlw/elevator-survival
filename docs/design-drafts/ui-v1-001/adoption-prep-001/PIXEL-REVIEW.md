重点资料见 [pixel-review.json](pixel-review.json) 的 64 项记录及 [pixel-measurements.json](pixel-measurements.json) 的 16 项重点测量。每项都带源摘要；未作完整边缘/实际接线审验的其他资产明确为未验证。没有把 alpha 通道存在当作清稿通过。

三组 5 态及玩家 v1/v2 均按原注册关系放入共同 1536×1920 画布，派生展示为 240×300 CSS 比例。脚点固定 `(0.5,0.92)` 是历史作者的支撑中心，不等于每张图最下方有色像素的同一水平线：两脚前后、跪姿和手着地可以自然变化。不得逐张 trim 后贴底来伪造一致性。`alpha>=128` 主体变换范围逐项记账，没有把原生低 alpha 噪点裁掉。命中锚只保留候选位置；护工低姿态时偏上身，尚未审成逐击 FX 锚，不在 C2 启用 FX。

无损 `derived/edge-*.png` 是固定原图的 96×96 原像素裁片，在浅/深底上 2×最近邻显示。裁片选取主体头缘与可见支撑下缘，全部在原生画布内；完整注册脚点另列，不把两脚间的空气误作鞋缘。没有做去底、补边、锐化、放大新美术或覆盖源图。`*-group.jpg`、`player-comparison.jpg` 和 `overview-*.jpg` 是标明 DERIVED 的缩略/叠底对照，JPEG 不用作原像素边缘证据；原图入口始终提供未改字节。

18 背景中 17 张为 1672×941，`bg-workshop` 为 1672×940。前者在 1200×888 CSS 槽的 cover 约为 0.943677，实际可见原生区域约 1271.622×941，相当于 **1.059685 原生 px/CSS px**；DPR2 需要可见 2400×1776，按原比例完整补源至少 3156×1776。workshop 的密度更低，为 1.058559，对应完整补源至少 3160×1776。18 项均 `OPEN_INSUFFICIENT`，详见 [background-audit.json](background-audit.json)。源尺寸、注册画布、CSS 槽和 DPR 分列，未用插值补足。
