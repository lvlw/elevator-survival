# 既有素材准入审看约定（本任务，不是DEC或UIR）

## 事实与状态

正式玩法/公开知识仍以后续确认DEC为准；UI约定读09当前有效节及UIR-012/015。设计R2尺寸/锚点是候选表现层来源，不自动覆盖当前生产UI，也不批准新信息披露。

必须分清：源码已接A/B1/C1；历史设计/注册画布；实际原生像素；本次候选；Owner批准；实际接线；真实浏览器；Owner体验。候选“可用”仅指建议可进入Owner审阅，不得写PRODUCTION_READY。

## 元数据

Canonical source digest=在固定源提交以Git blob实际字节算出的SHA-256，gitBlob为Git对象SHA-1，二者不混用。工作区换行摘要单列，不能默认所有文本规范化后hash。若只有工作区字节而无Git对象，写未验证。目录中的来源版本不推断为最新。

不原地改历史catalog。新候选清单是一次采用提案，不读取/驱动正式UI，不形成平行运行事实；将来获批接线时须明确唯一采用清单和旧项局部覆盖关系。

## 像素与视觉

1. 真实尺寸与源图可解码只证明材料存在；alpha通道不证明边缘无白底/黑边。对需要透明的主体至少用浅底、深底、已有相关场景底检视，边缘放大须标派生。
2. 15敌人槽按三组×五公开阶段逐项对应。无混用敌人、无假装全部原生可达；“失去能力”不得绘制/文案隐含已经死亡或胜利。
3. 玩家背身只比较现有当前候选，历史未采用项若作历史对照必须独立标明，不自动恢复或推荐。
4. 原生分辨率、注册SVG画布、CSS槽、DPR、缩放及裁剪各自标记。既有18背景2×门槛未解决仍OPEN；不以插值/更大容器关闭。
5. 共享底板必须保留地点适用范围、可见知识和遮挡区，不将医院图映到任意地点或把未到达信息画进公共地图。
6. 相邻阶段的辨识度、脚点/命中锚对齐、主体裁切、五阶段一致性及预期显示尺寸必须有真实图像对照。缩略总览不能代替重点原图审看。
7. 不生成新美术，不做alpha修复，不裁切改写源图。对照页或对照拼版只用于审查，不可作为素材原件/生产UI截图交付。

## 安全和只读预览

资源只来自固定仓库相对路径及本任务派生件。拒绝外链、脚本SVG、任意执行/请求、路径穿越、越界软链。预览服务只绑定127.0.0.1，仅暴露本任务和列明已有设计资源；不暴露.git、环境配置、用户文件或存档。不开公网。

对照页不读取玩家真实存档或隐藏状态，不导入正式游戏入口，不模拟“真实操作已提交”。图片展示按钮、切底色和放大都是静态审阅控件，不产生游戏效果。

## C2候选边界

C2只提出首批美术安全映射的可审核方案，不实现。当前对手事实只读正式A的kind/visualKey/name和已有公开阶段；图片选择留在呈现层。不存在或unknown保持明确中性降级，不能按地点/旧场次猜。错误/未完成整组不能隐式拼接旧成员；需要保留的旧成员须显式列原路径和摘要并等待批准。

C16缺口不被改名关闭。采用后涉及布局或动态的新实现仍须真实浏览器复验；静态候选审阅不能替代。
