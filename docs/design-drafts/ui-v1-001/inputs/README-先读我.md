# 第一版正式UI设计任务包

执行任务：`WORLD-UI-DESIGN-001`。

1. 读《第一版正式UI设计任务书-v1.0.md》，这是完整任务与权限范围。
2. 读`SOURCE-BOUNDARIES.md`与`尺寸耦合合同-v1.0.json`；后者是新设计起始预算，不是旧UI实测。
3. 逐张查看`references/`六张原图，仅继承视觉方向，按任务书纠正图中未批准机制。
4. 运行`python verify-task-package.py`和`python verify-dimensions.py 尺寸耦合合同-v1.0.json`；本包提供的是任务输入核验，不代表设计已经完成。
5. 进入设计任务，不改生产，最终交真实图稿／分层素材／原型、准确SHA和两个设计ZIP。

Owner无需解压，直接把此包交给设计会话。执行者在仓库外解压并定位材料。

本任务需要图像制作与可编辑设计产物；不得将“代码会话已读文件”或“写了提示词”当作已出设计。推荐模型及推理档位由Owner在会话外设置，不写入任务权限。
