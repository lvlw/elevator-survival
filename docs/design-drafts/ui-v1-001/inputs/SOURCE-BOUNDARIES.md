## E. 当前需写入设计交接的接口缺口

1. 连续CTB标记／速度动画：当前安全查询为当前玩家决策和相对先后；设计演出不等于新增私有字段访问。给出需要的公开事件／位置字段、暂停与回放合同，后续另审。
2. 敌人名称／素材映射：当前UI曾因缺安全映射而用中性占位。设计阶段可按正式三敌定义制作正确资产；生产接入不能仅猜地点或读隐藏definition/instance。提出最小只读公开呈现键的契约候选，不在本任务改DTO。
3. NPC形象与交互：形象可以制作；可操作内容只能对应实际已有行为。图片不创造对话树、支线或商品。
4. 目标与跨区域摘要：优先使用既有公开目标／地图；若缺字段，标记接口责任，不让React从完整存档推断。

以上缺口不妨碍出齐静态稿与明确标记的设计动效原型，但不能宣布后续运行时接线已经完成。
