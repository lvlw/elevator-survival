# 有限素材方法验证

先验证方法，未扩展批量素材。两次内置 image_gen 调用：H5高像素供给1次、玩家背身alpha清稿1次；均未达门槛，主动停止。没有使用付费API、模型下载、外部网站抠图或插值冒充高清。

H5请求原生3200×1800以上，保持门、冷柜、桌面、构图和focal。实际1672×941，1200×888 cover有效比1.0596847，低于2。重新生成不等于原生2×，不继续扩展供电所或隔离走廊。

玩家请求仅清透明边缘且保留RGB/轮廓/脚点/管口。实际尺寸1122×1402，但450088个RGB像素发生变化；1:1头发、衣摆、手和鞋部对照显示衣料与光泽被改写。不能将alpha数字变化当成功，不继续扩展装卸工五阶段或通信模块。

量化证据在 [art-methods.json](validation/art-methods.json)；[四底对照](review/alpha-four-mattes.jpg)是QA合成，不是新角色资产；[原尺寸ROI](review/alpha-roi-native.jpg)保留1:1细节。场景底为验证合成缩放，不用于声称源图新增分辨率。没有修改R2默认图，原件与失败候选在仓库外CANDIDATE-ASSETS包保留。

本工具接口没有显式像素档位或alpha-only蒙版入口。当前方法不足已经证实；下一次应先取得可保留RGB的独立蒙版工作流或确有原生像素预算的制作源，再决定批量扩展。此处不是新的工具采购或工程授权。
