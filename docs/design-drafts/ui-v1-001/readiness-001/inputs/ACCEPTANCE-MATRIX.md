每行分别记录作者执行、工具限制、未执行和待主线/Owner项。V07/V08即使未通过，也必须交付有边界的能力验证结果；这不自动阻止其他行正常交付，但总体不能称高清美术全部完成。

浏览器缩放与模拟viewport不同；截图/静态原型与真实生产链不同；schema合法与美术好看不同；导出一致与Owner体验通过不同。不得把这些口径合并。
