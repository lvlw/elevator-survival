# 设计主题替换规范 v0.1

这是闭合的设计试验格式，不是生产 SDK、任意脚本主题或商城。机器校验通过只证明格式、依赖与像素绑定，不证明美术合格。

## 固定与可替换

R2 三栏、24真实格、跨格 footprint、普通面板分档、最大态、1536×1920呈现画布、脚点／命中锚和9px/−3px/2°包络均冻结。主题仅改变受审图像与色彩表现，不拥有状态、成本、请求、确认、存档或实体身份。呈现画布不得当作原生像素。

`catalog.json` 含64原栅格及17注册SVG、5个代码原生组件，不能声称所有资源总数是64。地图节点／连线、HUD、按钮、九宫格、FX均记录代码定位；CSS URL扫描和共享SVG引用也列入依赖。旧玩家v1标 HISTORICAL_ONLY；未观察的条件素材不标运行时已覆盖。

八类模板：背景（cover＋focal＋遮挡区）、近景（8:5槽与主体）、玩家/NPC（姿态与透明）、敌人（五阶段整组）、物品/装备/任务物（contain＋格位＋菜单/详情）、边框/控件（九切边与文字）、地图/状态（只读知识）、FX（命中锚与动态安全）。各实例的像素、摘要、alpha、色彩假设、safeZone、slots、canvas、foot/hit、motion、publicCondition、反向依赖与检查见目录；不是空泛通用尺寸。

## 三份可用模板

复制 `bandage-test.json`、`porter-test.json` 或 `frame-test.json` 作为设计工作副本；不要改历史目录。稳定 key 与文件版本分离，旧 ID 留在 legacyId。绷带一个源同时覆盖物品、快捷、药食与详情；装卸工五件必须同时齐全；边框同一源负责九区，不能只换截图里的某个角。

本批实际模板用 SVG 嵌入原字节 PNG，加可逆 feColorMatrix 青色演示，标 TEST；没有新细节、清稿或造型采用。允许的 SVG 仅 svg/title/defs/filter/feColorMatrix/image，数据图只含原PNG；拒绝脚本、事件、外链、字体、任意CSS和额外规则字段。恢复 baseline 只换呈现，不重接／补物／恢复资源。

JSON闭合字段由 `tools/theme_check.py` 执行；新增或遗漏字段均拒绝。资源必须有稳定key、相对路径、SHA256、真实尺寸/格式、alpha、来源摘要、固定几何及状态。拒绝空路径、绝对路径、URL、`..`、重复键、失效文件和软链接越界。校验所有成员并解码后才发布一组；失败保留原主题，不能隐式拼接旧阶段。若将来允许保留旧成员，须在新受审清单显式列明来源与摘要；本批不实现隐式保留。

## 如何替换

1. 找目录的逻辑 key，先看反向依赖的节点、物品、页面族、槽与动态检查。
2. 按该项原生像素和alpha准备资源；保持脚/命中锚与画布。PNG、注册SVG、语义物品key不能互相冒充。
3. 更新工作副本路径与实际摘要。运行校验器；本批只接受三组受限 TEST 配方。新的最终美术格式须单独审查扩展，不能把 TEST 改名 PRODUCTION_READY。
4. 在作者模式选择 TEST 主题，核对实际像素、九宫格四角、多格轮廓、最大/普通态与上下文；玩家模式无导出监听。
5. 生成增量清单与包。被复用的R2资源明确列为 baselineReuse，收到轻包的人不能被告知它自包含。

美术门槛仍 OPEN：18背景原生2×、最终透明清稿、Owner观感。背景1200×888的cover有效像素比按 `1/max(1200/Sw,888/Sh)` 计算。注册画布、DPR模拟、插值或更大文件都不能关闭门槛。


## R1 浏览器与 CLI 内容校验

两入口均核对 SVG 根尺寸、单一内嵌图片及尺寸、原 PNG 的 SHA-256 与解码尺寸、唯一 matrix 类型、20个有限且绝对值不超过1的数值、alpha 行 `[0,0,0,1,0]`。数字词法统一为有限十进制／指数形式；拒绝 NaN、Infinity、截短矩阵和透明度改写。原路径权限、闭合元数据与整组校验保持。

先校验并解码整组，之后才启用；拒绝保留原主题、场景、对象及参数。三份合法 TEST 和 baseline 回退仍有效。使用 [同一夹具清单](../r1/fixtures/cases.json) 分别执行 CLI 和真实浏览器入口，详见 [R1 报告](../r1/report.md)。浏览器试验页只在 `r1/` 路径替送指定夹具响应；不扩正式加载路径。内容通过仍不等于美术通过。
