### 普通面板按内容分档（落实已记录方向，不一刀切）
原预算使普通面板在五桌面档占中央约79%—94%，与放大态差别不足。
把简单信息/短结果、必要参数、复杂整理/地图/战斗分为用途不同的容器。
- 简单内容可从约600×360的设计候选起步，按文本与控件自适应；它不是所有视口的硬规则。
- 参数明确且内容少时不套巨大空白面板；复杂材料/格位保留足够实空间及必要放大。
- 背包、地图、战斗可以使用更大的正常态；战斗低高度仍保证主体可辨和操作可达。
- 不缩小正文字号来凑尺寸、不把必要字段藏掉、不让主动作位于页面外。
- 保留外围任务/携带，不修改只读地图、真实6×4、两快捷位和一次点击规则。
- 只改设计稿及设计token，不擅改正式UIR或生产合同。

先在母版实际检查六个代表状态：物品详情、任务短结果、NPC、药食、样本参数、完整背包/战斗。
