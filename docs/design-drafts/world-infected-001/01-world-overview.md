# 完整感染世界设计 Draft v1.3：世界与连续角色循环

> **DESIGN DRAFT — WORLD-DESIGN-003 · 2026-10-02。** 当前委托《封锁区·未完成的转运》。本轮是基础补给、医疗成果解锁、出发衔接与较轻失败政策的候选生产，不是正式DEC、玩法实现、经济平衡或Owner体验批准。旧医院及main保持原样。

## Owner阅读入口（一页摘要）

**当前体验主线。** 进入五图封锁区，携回指定样本并恢复当地急救转运；真正生还完成后取得任务积分与合法携出物，在中枢选择付费恢复、保留积累或购买下一次准备，再以同一角色继续。五图和本地主线已由Owner确认／暂定采用，本轮不再重开。当前委托允许承担代价失败生还；这不是所有未来任务的统一退出政策。

**补给与成果解锁。** [11积分与中枢恢复](11-points-hub-recovery.md)推荐成功120；身体服务仍按真实病因20／40／80，健康不收费。口粮10、金属12、布10、电池12默认有购买资格；当前角色首次正式完成整项感染委托，同时开放绷带18与急救包45。购买产生真实单位，吃、用、维修、装包分别执行。0积分没有购买力；资格不随花钱下降，普通场景药物不受兑换资格锁。电子元件不售，工具箱长期缺口显式保留。

**回归和继续。** 正常生还先结合法所得，保留真实身体，在静态中枢选择治疗、吃饭、采购、维护和装包。没有强制独立中枢休整按钮。明确下一次出发先验证完整资格、身份、版本与携带，再用整备后的事实结一次应发生的角色周期，尚活才建立新任务；首次新角色入场不先白扣一天。先治好感染就不再按返航旧感染扣血，但身体服务不包口粮。出发时真实死亡不会倒改上次成功，也不会生成可玩的新任务。

**失败主案与诚实比较。** 主推荐为失败扣最多20现有积分、保留合法普通携出；旧最多30加回收未用新获物仅作对照。两案都不倒扣已经发生的药效、进食或维修，0积分实际扣款0且不形成债务。20E药房与50E物流前柜分别在共同规则下重跑十次新执行：前区无战斗与手工开柜带来的安全补给是真实收益，不能靠同一来源一次性就宣称新委托无法刷取。失败能够止损与可能退化成机械补给循环两种效果同时报告。

**采购必须进入实际账。** 世界固定可搜口粮仍6份，酒店另有交药换2份，医院无固定粮柜。中枢适配金属可真用于本地安装并减少重复搜索。连续主账保留269E正常路线，采购补维修缺口；出发前吃1、真实装1，衔接后在H0吃随身1。旧先中枢休整、再从仓库吃2的时序不再作为本轮证明，62／112／782均仅属v1.2历史。

**本批核心审查不超过三组。** 小目录和医疗首批的策略空间；较轻失败代价及供给的刷取取舍；末日异地出口与同周期衔接。末日仍是Draft，不随正常出发编排自动批准。实际分类结果、连续资产、独立批评与输入指纹见[完成报告](WORLD-DESIGN-003-completion.md)、[08](08-balance-budget.md)、[09](09-design-critic.md)。

## 玩家所处的世界

封锁街区有人与设备等待转运。旧广播播放过期接驳流程，危险支路曾被人为切断。玩家核查应隔离与恢复的部分，取得控制组件和匹配模块，在H8完成当地升降机与担架通路，再携样本实际回H0。样本不是燃料，普通电子件不制造跨世界能量。故事没有要求集齐三张纸、访问五张图或清空所有敌人。

林岑在T1提供有限医疗交付，周衡在L5及同源工单提供可选手动方法；两者不垄断主线资格。样本可早取或晚取，设备与供电可合法调整先后。单精力、已知真实路线、权限、危险、实物、容量与七日任务窗口决定节奏，换图不推进日期。

地图五张、24节点、H0返回点与七日期限属于当前内容。更长任务或不同入口应替换相应内容与合同并重新预算，不能把“接口可配置”说成任何扩展都已平衡。另一任务政策只做独立夹具，不建设真实第二世界。

## 职责与一次确定性结果（设计合同）

| 唯一事实／职责 | 本轮输入与结果 | 不能代行的工作 |
| --- | --- | --- |
| 当前任务执行 | 本次目标、期限、合法出口、终止结果与对应收入资格 | world名称不等于执行身份；结果页不再次发奖 |
| 角色积分 | 来源明确的收入／支付／失败扣罚请求，非负整数余额 | 不认识医院、床位或病种；不创建第二份可改钱包 |
| 历史成果与目录资格 | 当前角色真实完成整项委托事实及其派生的可购资格 | 当前余额不代表等级，消费不倒退资格，解锁不自动发物 |
| 身体与病程 | 健康事实、感染进展／暴露、声明的生命后果和治疗效果 | 病程不独立删角色；HP恢复不暗清其他状态 |
| 角色日与任务日期 | 角色周期唯一检查及刷新；任务日与已经结过的截止周期分别记录 | taskDay1不自动刷新角色日，不因报价或现实等待推进 |
| 物品与装备 | 唯一单位／ItemState、来源、容器、消耗、维护与实际移交 | 展示日志与来源账不是第二份库存；后续死亡不改写已交付、已回收等终结处置 |
| 世界与敌人 | 具名设施、危险、已兑现来源、同一敌人连续状态 | 新日期不重刷；另一任务不直接复用旧任务成果 |
| 精力与探索 | 逐行动合法性、真实路线成本、A/C目标重设 | 不是第二时钟，不控制积分、疾病或返回身份 |
| 展示与查询 | 玩家安全的资格、报价、结果与已知危险 | 不自行扣款、发物、治病或在订阅回调分次提交 |

先验证完整前态和请求，再确定唯一结果、应用全部相关变化并形成稳定后态；各体系在同一次受控结算中组合，不靠任意异步订阅分别发奖、清家底或保存。所有原子性/幂等检查仍只是设计模型证据，未验证生产存档事务。
