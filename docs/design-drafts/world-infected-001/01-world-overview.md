# 完整感染世界设计 Draft v1.2：世界与连续角色循环

> **DESIGN DRAFT — WORLD-DESIGN-002 · 2026-10-02。** 当前委托《封锁区·未完成的转运》。本轮是积分、身体恢复与连续任务的候选生产，不是正式DEC、玩法实现、经济平衡或Owner体验批准。旧医院及main保持原样。

## Owner阅读入口（一页摘要）

**当前体验主线。** 进入五图封锁区，携回指定样本并恢复当地急救转运；真正生还完成后取得任务积分与合法携出物，在中枢选择付费恢复、保留积累或购买下一次准备，再以同一角色继续。五图和本地主线已由Owner确认／暂定采用，本轮不再重开。当前委托允许承担代价失败生还；这不是所有未来任务的统一退出政策。

**回报与恢复推荐。** [11积分与中枢恢复](11-points-hub-recovery.md)推荐完整成功120积分，按实际病因分档报价20／40／80，身体健康则不收费；合法本次成功所得可立即用于显式治疗。先以身体服务＋首次真实成功后可购买绷带18的小目录验证积累用途，急救包等仅留少量未来候选，不建经验、等级、卖物或完整商城。奖励不随损伤或余额暗调，不预付给未生还者。

**病程纠偏。** 撤下旧稿感染120即结束尚有HP角色的候选。感染按[02](02-seven-day-structure.md)的明确日级检查点增长并产生生命损耗；HP0才进入唯一死亡。合法H0返回不补未来一晚，HP1重病者仍有真实中枢付费治疗窗口；实际已死者不发救命奖励、不复活。

**失败与连续准备。** 推荐失败扣最多30现有积分，并回收本任务新获而未消费的普通物；保留旧携入物、旧仓库和真实身体／装备。此项替换旧粮金罚，不把积分罚、旧物资罚、全包丢失和治疗费不加解释地叠在一起。下一委托准备需明确的角色日衔接，不能只改taskDay就赠精力或刷新日次数。详情只由[唯一终局稿](reviews/endgame-candidates-v1.1.md)与11定义。

**真实风险。** 新获品回收能拦住20E取绷带后直接失败的囤物路径，但已在任务内用药／修装备的效果不可倒扣；零余额重复失败可能维持身体而不积累物品或积分。本稿联合核算至少十次及成功—失败—成功，不用“来源一次性”掩盖新任务供给。限制重复委托或收接取费会压缩零家底角色的再尝试空间，必须连同动机和可玩性判断。

**本批核心审查不超过三组。** 身体恢复及最小兑换范围；失败回收／处罚与重复委托供给；本任务末日异地退出政策。具体数字已有Draft，已确认方向和工程命名不再作为Owner问卷。实际结果、剩余风险与源指纹见[完成报告](WORLD-DESIGN-002-completion.md)，细账见[08](08-balance-budget.md)。

## 玩家所处的世界

封锁街区有人与设备等待转运。旧广播播放过期接驳流程，危险支路曾被人为切断。玩家核查应隔离与恢复的部分，取得控制组件和匹配模块，在H8完成当地升降机与担架通路，再携样本实际回H0。样本不是燃料，普通电子件不制造跨世界能量。故事没有要求集齐三张纸、访问五张图或清空所有敌人。

林岑在T1提供有限医疗交付，周衡在L5及同源工单提供可选手动方法；两者不垄断主线资格。样本可早取或晚取，设备与供电可合法调整先后。单精力、已知真实路线、权限、危险、实物、容量与七日任务窗口决定节奏，换图不推进日期。

地图五张、24节点、H0返回点与七日期限属于当前内容。更长任务或不同入口应替换相应内容与合同并重新预算，不能把“接口可配置”说成任何扩展都已平衡。另一任务政策只做独立夹具，不建设真实第二世界。

## 职责与一次确定性结果

| 唯一事实／职责 | 本轮输入与结果 | 不能代行的工作 |
| --- | --- | --- |
| 当前任务执行 | 本次目标、期限、合法出口、终止结果与对应收入资格 | world名称不等于执行身份；结果页不再次发奖 |
| 角色积分 | 来源明确的收入／支付／失败扣罚请求，非负整数余额 | 不认识医院、床位或病种；不创建第二份可改钱包 |
| 历史成果与目录资格 | 真实完成事实及其派生的可购资格 | 当前余额不代表等级，消费不倒退资格，解锁不自动发物 |
| 身体与病程 | 健康事实、感染进展／暴露、声明的生命后果和治疗效果 | 病程不独立删角色；HP恢复不暗清其他状态 |
| 角色日与任务日期 | 明确日级检查、药效／日次数、下一次任务额度 | taskDay1不自动刷新角色日，不因报价或现实等待推进 |
| 物品与装备 | 唯一单位／ItemState、来源、容器、消耗、维护与实际移交 | 展示日志与来源账不是第二份库存，身体治疗不维修装备 |
| 世界与敌人 | 具名设施、危险、已兑现来源、同一敌人连续状态 | 新日期不重刷；另一任务不直接复用旧任务成果 |
| 精力与探索 | 逐行动合法性、真实路线成本、A/C目标重设 | 不是第二时钟，不控制积分、疾病或返回身份 |
| 展示与查询 | 玩家安全的资格、报价、结果与已知危险 | 不自行扣款、发物、治病或在订阅回调分次提交 |

先验证完整前态和请求，再确定唯一结果、应用全部相关变化并形成稳定后态；各体系在同一次受控结算中组合，不靠任意异步订阅分别发奖、清家底或保存。所有原子性/幂等检查仍只是设计模型证据，未验证生产存档事务。
