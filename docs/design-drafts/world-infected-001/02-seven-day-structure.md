# 完整感染世界设计 Draft v1.1：七日结构、精力与休整

> **DESIGN DRAFT — WORLD-DESIGN-001R。** 本轮纠正上一任务书误带的日区域门禁。单精力与实际路线支持同日跨图；休整原位跨日。旧医院版本与正式DEC不改。
> **v1.1变更：** 删除来源区仅通行、目标日承诺、首次交互锁区及箭头跨日；机会表改为五图主案；端到端终局接入[完整候选](reviews/endgame-candidates-v1.1.md)；验证入口改为[可复跑证据](evidence/README.md)。

## 一天怎样发生

**已确认方向待落文。** Owner本轮明确纠正“一天一个主要场景”：它仍是旧医院／现行正式版本的事实，不能作为新连续世界硬要求。新稿没有每日地图计数器、当日主要区域、来源／目标区承诺或“交互一次就锁图”的资格。世界仍以七日为期限，日期只由显式合法日结算推进，换图不推进日期。

**授权内Draft。** Day1从医院前室H0开始，之后每天在真实休整节点醒来。玩家可在任一已合法到达的位置调查、搜索、处理事件，再沿已知且符合条件的真实路径进入另一地图继续工作；也可同日回访。每个动作分别检查精力、位置、路线知识、物品／工具、危险和前置。跨图本身不恢复精力、不清伤势、不刷新敌人、每日次数或来源，不提取物资到中枢。

- H→L→C仅表示访问顺序，绝不隐含三个日期。日期和每晚位置必须单列。
- 从医院完成调查后，只要下一行动时精力仍为正、路已知且可通行，即可继续到物流；物流核验仍须处理现场危险，不能借跨图跳过敌人。
- 来源地图可再次搜索、交付、工程；返回曾去过的地图也没有次数税。工作导致归零才停止新探索，不因工作发生在哪张地图而拒绝。
- 路径队列逐边执行和扣费。每条边都有独立开始资格；归零后剩余队列停止，不能将多条边、战斗或整图搜索合成一个巨大“最后行动”。
- 移动完整落在真实目标节点，才截断精力与处理该次立即危险；不存在半条边休整、免费回入口或退回出发点返还成本。
- 同日反复往返不刷新金属管标志行动。合法新日只重建一次日额度。

**ASSUMPTION — 最小核查例。** 在声明的安全／已知表层观察条件下：H0→H1（2）→H7（2）→调查工单（4）→L0（8）→L1（2）→用撬棍开前柜（6，耐久1）→搜索（8），合计32精力，仍为Day1、E68。物资需实际拾取；其后到L2必须处理危险再核验。此例的用途是拒绝日地图门禁与切图刷新，不是完整通关证明；执行结果见证据。

## 路线知识、阻断与停留

**授权内Draft。** [03](03-location-design.md)列出逐节点表层发现。到达只增加明确可见的路线知识，不把作者全图变成玩家已知。已知不等于可通行：实体门卡、物理门、当前敌人、已隔离旁路仍分别检查。已有知识跨夜保持，动态危险标最后观察时点；未访问位置不提供远程精确状态。

合法移动后归零时，人在边的终点。若该节点允许C休整且立即危险已完成，可原位过夜；若移动触发战斗，则先完成既有战斗或正式逃跑，不能睡掉危险。精力0不能再走向远处A床。未抵达原计划目的地不会消耗虚构的“区域机会”，也不会免除已发生的动作消耗。

**授权内Draft。** 五地图主案为H医院、T酒店、P供电所、L物流、C通信。T酒店为可绕开的准备与人物地点，P供电是实际供电工作位置；不是新增任务令牌。医院保留九节点，不为凑地图规模机械扩房。三地区整合仍是[比较中的紧凑备选](reviews/map-structure-comparison-v1.1.md)，不同时启用两份支路柜／NPC库存。

## Day1—Day7：机会窗口，不是强制日程

**ASSUMPTION。** 下表说明可能的节奏，不给当天访问次数或最低成功日。每一天均可在精力、路线、资格与危险允许时跨图和回访；“访问了五图”不等于“至少五天”。路线按实际动作与风险重算，不能沿用旧一日一区账的日数作为证明。

| 日 | 可能的工作组合 | 收益与取舍 | 必须保留的后果 |
| --- | --- | --- | --- |
| Day1 | 医院调查／医疗后去物流；酒店准备后到供电；直接物流或通信 | 早取样先完成一条成果线但占格；先工程减少负重；酒店与NPC均非必去 | 只公开目标和方向，内部路线逐步发现；不能免费取得物资或逃过首次危险 |
| Day2 | 在醒来处续办，接续其他地图工作；同日核验、取件、供电均按资格 | 无日门禁后可把余量用于真实后续工作，不用为短交付强睡一夜 | 敌伤、工程、来源保持，物品持续占实际容器 |
| Day3 | 汇合两部件与安装料，回医院处理样本／装接／返航，或补调查 | 条件齐备可离开；也可能仍在处理风险分支，无统一三日保证 | 成功必须实际到H0；不得用标价之和替代逐行动合法性 |
| Day4 | 继续未完成的前置，或有理由地取可选成果 | 后半程价值来自未办工作与已知机会，不重刷前三图 | 期限提示仅展示；不自动加怪、重锁门或补来源 |
| Day5 | 受损者止血、补给、修理、换路或主动失败生还 | 继续推进与结束委托的取舍由当前真实状态决定 | 休整不回血；备用材料仅在尚存、可达、可取得时有效 |
| Day6 | 收敛缺项并安排末日实际位置；仍允许同日跨图 | A/C选择看次日后续位置和当日机会成本 | 不为保证终日成功传送、赠药、免路费或隐藏处罚 |
| Day7 | 正常工作、跨图、补目标并到H0返航；也可显式截止结算 | 正常H0返航不补夜；目标未全亦可H0主动失败生还；显式截止另按候选日级后果 | 无Day8普通探索；异地到期、致死及实物去向按明示终局候选 |

日期压力来自有限精力机会、实际食物、感染与最终窗口，不另加每天必战或现实倒计时。完成任务后继续取可选成果仍属尚未终止的世界；显式返航终止后不能再探索。

## 当前模型与参数边界

**现行规则事实。** 医院实装为200场景时间、CTB、归零强制返程与日结算，不是已有本稿精力体系。旧配置按原版本生效，见[冻结快照](../../06-vertical-slice-design-freeze-v0.1.md)。新世界拟局部覆盖见[01](01-world-overview.md)。

**授权内Draft／ASSUMPTION。** Day1工作起始精力100、上限100，A目标100、C目标85。目标重设不是相加：95在C过夜后为85，10在A过夜后为100；健康、饱食、伤势和感染不修改目标，死亡或终末不生成次日。没有药物、现实等待或切图补精力；在本期固定上限100内，调整目标的试验范围可为A95—100、C80—90，但不得暗中改变已执行证据参数。

剩余精力>0才可开始普通消耗型探索；即使价格大于余额，合法单次动作完整完成后截到0。单位物资、位置、前置与空间不享受不足额让利。无负精力、翌日补扣、额外生命罚款或旧超时债务。移动负重／伤势的各独立倍率相乘，最终统一向上取整一次，具体参数与逐步价格读取[证据参数](evidence/parameters.json)。

**授权内Draft — 战斗。** 单敌人CTB负责行动先后；候选精力成本为 `max(6, 4×ceil(实际经过CTB/100))`，每次遭遇结束一次扣费并截零。已被合法行动触发的战斗在精力0时继续合法攻击、防御、快捷医疗及逃跑，不能用过夜跳过；死亡优先。脱离回真实允许的节点，同一敌人的剩余生命、下一意图与风险进度持续。零精力不能另开移动触发另一战斗。没有叠加旧场景时间。

## 零精力、安全点与动作粒度

下表为**授权内Draft默认**，不是逐项已获正式批准。

| 行为 | E0时 | 仍须成立的条件 |
| --- | --- | --- |
| 查看已知信息、地图、预览 | 允许 | 纯查询，不改变事实或消耗随机 |
| 整理、显式拾取已揭示物／丢弃 | 允许 | 同一真实节点与实例、数量、容器／堆叠／几何合法；不得把任务提取改名为拾取 |
| 随身药食自救 | 允许 | 已持实物、医疗目标／饱食／每日次数合法；稳定非战斗；不恢复精力 |
| 新移动、搜索、核验、NPC交付、提取、工程装接 | 禁止 | E>0只是必要条件，仍检查位置与前置 |
| 维修与充能 | 禁止新开 | 真实材料／电池与对象条件；不形成零值免费整备 |
| 合法位置原位过夜 | Day1—6允许 | 无活动战斗／待立即结算危险；后续先处理日级危险 |
| H0正式返航 | 允许 | 生还、在接点、无未结算立即危险；判定实际目标／物资结果 |
| Day7显式截止结算 | 允许 | 稳定状态；按终局候选终止，绝不生成次日精力 |

非战斗自救在正值和零值均0精力，实际消耗药食并检查资格；不奖励故意先耗至0。它不触发正标价探索的流血检查，非止血品也不移除流血；CTB战斗医疗仍用真实快捷位并按战斗行动结算，不通过该白名单绕过。

流血无实时扣血：CTB内按完整玩家行动检查；世界探索每次有意义的正标价移动／搜索／工程／任务行动后检查一次。最后越零行动仍检查。纯查询、拖动物品、免费自救不变成新的伤害计数器；止血先完成真实治疗效果。不把原来一次工程拆成多次点击以重复扣流血。

A级点为H6、T1、L5、C4的明确安静区；其他允许C的节点与敌人清除要求见03。不是任意房间都安全，也不以邻图有敌人为由禁止当前安全位置休整。当前草案不配置“最后合法移动后既无法处理危险也无可停留位置”的无说明必死格。

金属管标志行动按一次合法游戏日最多一次，切图、重新交战、读档不补；医疗日次数在真实且生还的日期推进后重建。换任务的Day1编号不单独刷新未到期日次数或标志行动，见终局候选§7。没有每日免费维护工时。

## 休整与日期：固定职责、一次结果

**授权内Draft。** 确认前展示所在位置、精力目标、已知饱食／流血／感染后果与物品留置；不自动用药、吃饭、维修、拾物、补快捷栏或走到床铺。

1. 验证尚在活动世界、当前位置允许、无活动战斗／不可中断事件、Day1—6。
2. 处理未止血等持续危险；已致死则停止后续普通阶段。
3. 结算感染暴露、已有进展和抑制；达到终末则停止后续阶段。
4. 处理饱食及匮乏；致死则终止。
5. 仅生还时处理药效到期和次日使用次数；不自动回血、治伤、修理或充电。
6. 依原位A/C重设精力、日期+1；位置、实际携物和世界成果保持。没有区域承诺可重置。
7. 一次验证完整结果并提交，之后只读通知。重载／重复确认／展示订阅不再结算；保存失败不重跑玩法。

| 条件夹具 | 预期 |
| --- | --- |
| HP9、饱食6、无暴露无流血，C过夜 | HP9、饱食4、次日E85，无回血 |
| HP9、饱食2，其余同上 | 饱食0、匮乏-1、HP8，次日E85 |
| HP2、未止血，合法休整 | 流血2致死，后续感染／饱食不执行，无次日 |
| E1、合法移动标价8 | 到边终点后E0，不欠债，不能再走另一条边 |
| E95、已在C，明确过夜 | 次日E85，不叠加或保留差额 |
| Day7、活着在H0、任务齐备、E0 | 显式成功返航，不补第七晚 |

## 末日、主动止损与下一任务

**OPTION／待Owner核心决策。** 四种结尾的完整输入、实物账、处罚和下一阶段只在[终局候选主文](reviews/endgame-candidates-v1.1.md)定义，04及本页引用，避免各写一个“未来处理”。主组合区分H0真实完整成功、H0主动失败生还、Day7异地截止失败生还、已发生死亡；异地召回属于明确新候选，不是现有正式规则的默认救援。

H0完成或主动返航不额外补夜；Day7显式截止结算可有自身已公开的日级危险顺序，但不会让一个尚活的人仅因目标未成就自动死亡。实际死亡始终先判，召回不能救回死者。普通合法携出物延续与死亡失去角色家底是已确认方向，具体罚则及跨任务接口候选仍单列待审。

## 更长世界与证据边界

日期职责使用世界期限，不用本世界第7天替所有未来世界硬编码；有限来源、医疗、饱食及长期家底仍需对更长期限重新预算。不得通过重刷旧柜、NPC补满或无代价治疗推得三十日可行。

本轮[08](08-balance-budget.md)与[evidence](evidence/README.md)保存参数、行动序列、错误路线、逐步资源及几何、原始输出和复跑命令。它只验证明确候选的有限输入，不是生产规则引擎、随机抽样、存档恢复或Owner体验。生产单项／组合／严格恢复／UI与三专长三工具覆盖仍需后续正式实现与验收。
