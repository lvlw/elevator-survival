# 完整感染世界设计 Draft v1.0：七日结构、精力与休整

> **DESIGN DRAFT** · 主方案为世界内连续驻留。与[01总览](01-world-overview.md)、[03地点](03-location-design.md)、[08预算](08-balance-budget.md)配套；本页不改医院旧版本。

## 一天怎样发生

**CONFIRMED INPUT。** Owner 本轮已确认连续驻留和休整方向并授权细节；任务书仍要求每天一个主要场景。本世界仍是七日期限，提前完成不追加夜晚。后续更长世界是架构复用目标，不是本包开放Day 8的理由。

**DESIGN DRAFT。** 每日开始于实际醒来的节点；Day 1开始于医院前室。玩家选择留在当前区域探索，或沿已知可通行路线付精力进入一个相邻目标区域。留在原地进行首次搜索／任务操作，或确认跨区出发，便承诺当天主要区域。不会因为看地图、整理背包或取消预览而锁定选择。

- 跨区当天，起点区域仅允许走向出口、查看已有信息及使用已经携带的自救物；不先搜索、交任务或装接，再把第二地区当成“当天唯一主要区域”。
- 若出发路径有尚未解决的敌人或障碍，预览不把它算作安全过境。玩家可选择留在原区解决。确认转移后现场发现原先未知的阻断，或明确世界结果造成的新阻断，允许原路止损，仍占当日主要区域承诺，不赠第二次探索机会。
- 进入目标区后从实际抵达节点继续，切区不补精力，不结算过夜，不把物资远程入库。普通连通为医院↔物流、物流↔通信、通信↔医院；额外捷径只是改善路径。
- 日终在当前合法节点显式过夜。次日仍在该节点，日承诺重置；角色、携物、敌人和设施不传送、不重建。
- 同一区域内往返是正常付费移动，不新增“再进图”费用。恢复存档仍是同一时点，不重置日期、精力、战斗或来源。

**DESIGN DRAFT — 初日过境知识。** 入场委托公开医院前室至通信入口的区域方向；医院前室表层观察只公开到大厅的本地边。选择向物流过境时，先按已知边走到大厅，由大厅明确的新世界表层导视发现大厅—后勤边，再到后勤观察物流出口；不预先显示后勤内部全图。过境中的这些逐步观察不算额外搜索，也不消耗第二次主要区域机会。每条尚未发现的边必须先获得明确观察，自动路径不能越过未知边。

**DESIGN DRAFT — 转移未抵达。** 移动按一条真实边完成后再截零，角色落在边的目标节点，不停在抽象半条边。若在来源区走向出口时归零，当日目标承诺不变，不能借机搜索来源区；当前安全节点仍允许C休整、既有物自救和查询，下日重新选择，不因未抵达目标而锁死过夜。若跨区边使精力归零，实际抵达目标入口后可C休整。路径预览说明可能只能抵达休整位置；没有自动返还日期或精力。

**DESIGN DRAFT — 取舍。** 该方案保留任务书的每日区域承诺，但比自由跨图严格。若其导致玩家为短交付空等一夜，应重新审查区域限制，而不是伪造一道无缘由的门。见[决策队列](10-decision-queue.md#daily-region)。

| Day 6 | 三地条件访问 | 收敛最后的部件／样本／安装缺口，计划Day 7实际位置 | 任务推进、已知返航路线与明确材料清单 | 最后一次远区过夜可能使终日无法到达；伤势增移动成本 | 通信取模块→当地休整；医院取样待装接；物流取得实物 | 公开最后期限及去医院的已知成本，不替玩家自动赶路，不给临时免费补给 |
| Day 7 | 留原区或选最后一个目标区，医院为唯一最终回归区 | 在现有精力和携物下到医院，完成缺口并显式返航 | 完整成功；或已明确的失败生还候选结果 | 在错误地点精力耗尽；材料／任务实体不可恢复遗失；已发生硬失败 | 通信／物流→医院→装接／取样→前室；医院内完成 | 正常行动机会保留；不生成Day 8。到期未成按正式终局处理，异地不免费传回，不把任务失败伪装为死亡 |

**DESIGN DRAFT。** 日期增加带来的压力来自有限精力机会、真实食物、感染和最后期限。世界的其他改变以玩家操作和有来源信息驱动，不另加每天必袭、无提示道路封死或强制敌人升级。更多日世界可以配置不同期限和日级变化，但须有明确内容及预算。

## 三种贯穿路线

**DESIGN DRAFT。** 精确取得与消费账见08，下列顺序只表达策略。

| 路线 | 区域与休整安排 | 价值 | 代价／适用条件 |
| --- | --- | --- | --- |
| 调查型 | H准备／取样→L支路与控制组件→C调查／取模块→H装接回归；按实际精力在当地休整 | 较早确认危险与资源，可交叉核对记录 | 若Day1取样并随身带走，则占2×2／4重量；原位暂存需实际回取；多一天生存成本不是固定签到 |
| 先工程型 | Day1过境进C或L→另一设备区→H取样、装接、回归 | 减少样本长期占格，可能三日完成 | 现场替代核查要付真实成本；没有早期医院药物缓冲；并非所有状态或工具都能三日完成 |
| 受损调整型 | H准备→L前区补给→C调查→L取得控制→C战斗止损→C续办→H终段 | 已造成伤害和设施成果保留，展示七日缓冲用途 | 六个真实夜晚、持续携物和医疗；必须在真实状态下确认最后一天能完成，不保证所有撤退都能挽回 |

**CONFIRMED INPUT。** 不设置“第几次到访才允许拿件”；实际前置满足即可处理。同一具名敌人分段突破保留真实结果，不额外收撤退税或天然降评级。来源：[DEC-046、048](../../05-design-decisions.md)。

## 当前模型与接入候选

**CONFIRMED INPUT。** 当前医院实装的是200场景时间、CTB、时间归零强制返程与日结算，**不是已有精力体系**。旧数值和生命周期按原版本继续有效，见[冻结快照](../../06-vertical-slice-design-freeze-v0.1.md)。

| 方案 | 内容 | 适用性与处理 |
| --- | --- | --- |
| DESIGN DRAFT：主方案 | 单一精力承担区域转移、节点移动、探索、工程及战斗转换；实际位置休整建立次日额度 | 符合本轮确认；本包全部新路线按此推演 |
| OPTION：休整目标调整 | 保持相同语义，只比较A95–105、C80–90等配置 | 后续调参，不增加第二根探索预算，不引入S超额 |
| OPTION：旧日返模型对照 | 200场景时间、每日回Hub | 只用于解释旧切片及回归测试，不作为完整世界的推荐候选，不重新要求Owner选择 |

**DESIGN DRAFT — 精力定义。** 暂用固定上限100，Day1起始100；常规A目标100、C目标85。目标重设不是“当前值＋恢复量”：95在C点过夜，合法次日是85；10在A点过夜是100。健康、饱食、伤势和感染目前不修正目标；死亡或终末则根本不产生合法次日。没有药物、技能、奇遇或现实等待恢复精力。

**DESIGN DRAFT — 行动与归零。** 剩余精力大于0时，可开始其他条件均合法的单次行动，即使价格大于余额；完整完成后最低为0。无负精力、生命罚款、翌日补扣或旧医院超时债务。界面路径队列不能把十条边打包成一次“最后行动”；每条真实移动边分别判断。正精力许可不免除材料、权限、位置或任务前置。

**DESIGN DRAFT — 战斗。** 保留单敌人CTB作为出手顺序；候选遭遇精力成本为 `max(6, 4×ceil(实际经过CTB/100))`，在一次遭遇结束时结算一次，最低截零。已被合法移动／互动触发的战斗即使当前精力归零仍继续合法攻击、防御、快捷医疗和逃跑，不能休整跳过；战败优先终止。脱离后回到真实安全节点，敌人连续状态保留。零精力不能主动移动开启另一场遭遇。不会同时再扣旧场景时间。

## 零精力、安全点与操作粒度

**DESIGN DRAFT。** 在没有待立即结算危险、没有活动战斗的稳定节点，明确采用以下默认，作为可评审细节而不是逐条Owner已确认规则。

| 行为 | 零精力时 | 原因与成本 |
| --- | --- | --- |
| 查看已知信息、地图、合法预览 | 允许 | 纯查询，不改变世界、不消耗随机 |
| 整理背包、显式拾取已揭示物、显式丢弃 | 允许 | 物品必须已真实存在且空间合法；不替代提取任务实体，不自动拾取 |
| 使用随身已有绷带、急救包、消毒剂、止痛药、口粮、抑制剂 | 允许 | 消耗实物并检查所属体系资格／日次数；不恢复精力，不远程取仓库物 |
| 节点移动、跨区、新搜索、核验、NPC交付、装接 | 禁止新开 | 防止“零成本互动”完成整个世界；可查看此前已知报价 |
| 维修、充能 | 禁止新开 | 材料／电池＋精力；不是无限零值整备 |
| 已在合法位置的过夜 | 允许，末日除外 | 不能远程调用A级床；处理真实跨日危险 |
| 已在前室的正式返航 | 允许 | 是世界退出而非新的探索；仍检查生还、位置、任务与终局资格 |

**DESIGN DRAFT — 自救成本。** 上表非战斗随身自用药食，在正精力与零精力时均为0精力，实际消费物品且检查医疗目标、饱食上限和每日次数；不对同一行为按余额设置相反价格。它们不触发正标价探索行动的流血检查，非止血品仍不移除流血。战斗用药仍支付CTB并按战斗行动检查，不能用世界白名单绕过。

**DESIGN DRAFT — 流血。** 无实时掉血。CTB内继续按完整玩家行动检查；世界探索按一次有意义的正标价移动／搜索／工程／任务行动后检查一次，不按格子拖动或纯查看次数掉血；归零最后行动仍有该检查。世界非战斗自用药以实际医疗为主要效果，先处理治疗与止血，避免为了补零精力白名单偷偷取消医疗资格。新增细粒度互动的成本与流血检查必须作为同一动作设计；不把一件旧工程拆成五个点击再扣五次血。

**DESIGN DRAFT — 休整位置。** 医院值班休息室、物流值班间、通信检修间的明确安静角为A。其他已确认能暂时停留且无立即危险的节点可C；不是所有地点自动安全。当前内容不放置“走入后必定归零且既不能战斗／脱离也不能C休整”的无解格。敌人仍在的节点不能睡；打倒敌人后是否可C由该节点明确声明，不能因击杀而默认全区安全。

**DESIGN DRAFT — 每日额度。** 金属管标志性行动候选按一次合法新日的探索窗口最多一次，不随切区、读档或同日重入刷新；医疗日次数按成功进入下一日重设。维护没有每日免费工时。此处替代旧“每次Scene”含义，需要新版本正式落文，不新建运行时生命周期枚举。

## 休整与日期：固定职责、一次结果

**DESIGN DRAFT。** 显式过夜先展示实际地点、目标精力、预计已知日级消耗、流血／感染风险及留置物位置与最终携出提示。不能默认吃药吃饭、自动修理、补快捷栏、自动转移任务物或自动走去床铺。流程如下：

1. 验证正在进行、当前位置可休整、无活动战斗／不可中断事件、尚可进入下一日。
2. 处理仍未止血等明确持续危险；已致死则停止后续普通阶段。
3. 结算本世界感染暴露与进展；终末则停止后续普通阶段。
4. 处理饱食及匮乏；达到死亡则终止。
5. 生还时处理药效到期和新日次数；不接旧睡眠回血、自然消伤、免费修复或电量恢复。
6. 依所在地重设精力，推进日期及已声明世界结果，重置当日主要区域承诺；位置和真实携物保留。
7. 一次性验证并提交完整结果，随后发布只读展示通知。存档恢复、重复确认和订阅重建均不能再次跨日。

**ASSUMPTION — 局部算例。** 以下借用08的工作配置，展示顺序，不证明整局平衡。

| 起点与操作 | 预期结果 |
| --- | --- |
| HP9、饱食6、无暴露无流血，C休整 | 饱食4、HP9、次日精力85；无自动回血 |
| HP9、饱食2、其余同上，C休整 | 饱食0，匮乏减1，HP8，次日85；匮乏不额外修改精力目标 |
| HP2、未止血，任意合法休整 | 先处理跨日流血2致死，不再扣后续饱食，不给次日精力 |
| 当前精力1，合法移动标价8 | 移动完成后0，无债；不能再走向远处A点 |
| 当前精力95，已在C点，明确过夜 | 次日85；不保留旧15，不把目标当加值 |
| Day7、任务齐备、活着在前室、精力0 | 可显式正式返航，不补第七晚；任务实物仍须真实携带 |

**BLOCKING DECISION。** Day7在异地耗尽而未完成的终局、失败生还以及跨任务资产后果集中见10。候选不得产生Day8，也不无根据处死尚活角色；这不影响先完成七日世界的日内与普通跨日设计。

## 更长世界与验收边界

**DESIGN DRAFT。** 精力不读取“第7天必须结束”常量；日期职责消费世界的期限，健康消费明确日期事件，任务查询实际成果，来源消费独立身份。三十日或其他期限必须重新审查来源／消耗，不能重刷旧柜子或套用六夜粮食下界。

**DESIGN DRAFT — 待执行验证。** 应覆盖1精力最后行动、0精力拾取与医疗、不可把队列当单行动、战斗中归零、C95→85、休整死亡优先、跨夜不回血、注册顺序不影响结算、过期确认、保存失败、Day7无Day8、三工具三专长、自由试玩与分段对照。本次只完成文档与纸面核算，未执行游戏引擎或浏览器验收。
