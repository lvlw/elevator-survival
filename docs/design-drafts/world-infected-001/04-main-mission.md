# 04 主线任务：携回样本，恢复未完成的转运

> **DESIGN DRAFT — WORLD-DESIGN-001R / Draft v1.1。** 任务名称、地点索引和步骤不是新增运行时状态或实现授权；旧医院主线不改。本文引用 [统一终局候选](reviews/endgame-candidates-v1.1.md) 的结果与实物账，不另立一套返回罚则。
> **v1.1变更：** 五图主案；同日跨图无日承诺；P1供电、T1人物；C1匹配／C3提取统一；四种结尾接到具体下一活动；主线目的显式列为Owner核心审查。

## 推荐目的与待审取舍

**DESIGN DRAFT／待Owner核心决策：** 推荐委托为“第七日窗口结束前，实际携回指定密封病原样本箱，并恢复医院最后一条本地急救转运通道”。样本是独立回收实物；控制组件、启动模块和供电服务的是当地升降机与担架通路，不能解释成用普通电子材料制造跨世界通行能力。

这是对本地成果的主动推荐，**不是已批准的完整世界任务目的**。需要Owner判断帮助当地恢复是否应成为必要目标；“部件仅服务异常电梯脱离、本地转运可选”是另一核心候选，若采用必须重写必要成果与返回因果，不能沿用当前成功条件。详见 [目的队列](10-decision-queue.md#mission-purpose)。样本不作为燃料、不因看到或记录就视为携回，这些边界不重开。

故事矛盾是有人曾为阻止危险沿转运链进入安置点而切断支路，另一些人因此被困。玩家核查应隔离哪部分、恢复哪部分，再用真实部件完成工作。H7工单、P1封条与C5时戳帮助解释因果；故事不要求集齐三张纸，也不以清空全区敌人或强制NPC交药为委托条件。

**已确认方向待落文：** 世界内连续驻留，原位休整；一份精力按真实路线和资格支持同日跨图。医院、酒店、供电、物流、通信之间移动均不等于回真正中枢，不安全提取物资。旧医院一日边界继续留在现行正式版本，见 [01](01-world-overview.md)。

## 入场公开与实际取得的信息

**授权内Draft：** Day1实际起点H0，但不强制先做医院工作。入场公开指定样本编号、本地设施型号、控制组件及匹配启动模块两个功能缺口、安装需金属1＋电子1、供电需现场核查、最终返航点H0、最晚七日。街口只公开当下可知方向，内部图随 [03发现表](03-location-design.md) 扩展。

医院型号为委托真实信息，不是进医院一次才发的签到令牌。因此可先走H7方向到物流取得实物接口，后到C1快核；也可先在C1用医院型号和现场维护表完整匹配，再去物流快核。P1可先恢复也可后恢复，T1可绕开。精确敌人参数、所有柜内数量、完整内部路线和推荐日期表不作为免费情报。

普通消耗型动作均要求开始时 E>0，即使相邻两项在同一节点也分别检查。材料、位置、门卡、一次性来源和容器不享受最后行动不足额让利。未知路线不能进入导航；C1—C2卡件需在C1另付撬6＋耐久1或手动14，开通后进入C2仍处理原敌人；C4旁路另有调查和隔离成本。

**R4纠正：** 匹配只在C1，提取只在C3。原三日Day2“进C3快核4”保留为 [应拒绝检查输入](evidence/README.md)，合法新路线在C1支付4或6后再去C3。仅把原总和79算对，不能证明旧路线成立。C1完整6与L2完整6各有独立起点，没有互相需要对方首次访问的死循环。

**授权内Draft：** 样本不作为核验、取件、供电或装接前置。早取样先解决医院危险，但承担占格、重量与可能医疗消耗；可以战略留置后付真实路费回来取，不能远程交付。晚取样让中程包更轻，但把护工与污染风险留到后段。无额外腐败、隐藏消失日或强制收箱NPC。

H8装接完整成立后，升降机抵达接驳层、担架通路连通，现场回执确认当地人员开始接驳；不模拟实时护送，也不要求再跑C5、T1或L5盖章。样本仍是独立实物；设施恢复不直接产生成功或角色治疗。

## 依赖图：信息可减费，真实部件才安装

```text

  │          └── 可使L2核验由6减为4               │
  └─ P1核查6 → 隔离／恢复12 ──┐                    │
            真正安装金属／电子 ─┼→ H8装接验收 ─────┤
```

供电不依赖已装好的组件，通信维护旁路不依赖尚未取出的模块，组件不需要先交样本。第一次完整核验／匹配足以独立启动；信息可以先行，实体不能复制。

## 可以混合的工作顺序

**ASSUMPTION：** 表内箭头只表达访问与工作顺序，不表达日期、日区域承诺或生还保证。同日可以继续下一项或回访；只有实际过夜才记下一日。逐动作费用、每晚位置、风险分支和几何见证以 [08](08-balance-budget.md) 与 [证据](evidence/README.md) 为准，不沿用v1.0一日一区的旧总账。

| 倾向 | 代表顺序 | 真正的取舍 |
| --- | --- | --- |
| 西路工程先行 | H0→T0→P1检查／恢复→L2取组件→C1匹配／C3取模块→H8与H5→H0 | T0可只通行，T1服务可选；工程集中但西路及床位均有路费，医院危险留后 |
| 初见调查／早取样 | H1/H3/H7→H5取样或先准备→T1／P1→L5及L2→C1/C5/C3→H8→H0 | 解释断电与旧广播，早占格；H7调查后仍可同日去L工作，T1交药需真实余药 |
| 通信先行 | H0→C1完整匹配→C3取模块→L2快核／取组件→P1→H8/H5→H0 | 不需物流先访；早带模块、工程支路可能增加折返，需要留足末段医院行动 |
| 受损止损 | 当下安全节点→真实药物／尚存补给→续接同一敌人或C4候选旁路→完成缺项或H0失败返航 | 跨日战斗不刷新敌人，医疗和材料须已取得；每多一夜有食物／感染后果，不靠睡眠回血 |

**授权内Draft：** 已完成主线工作而尚未显式返航时，可以在期限内争取可选成果；一旦正式返航，本世界终止，不能成功后继续拾物。提前返回不补尚未发生的夜晚，可选项未完成不自动降低评价。

## 失败预警与仍可恢复的工作

| 当前问题 | 尚可采取的行动 | 真正边界 |
| --- | --- | --- |
| 未取到目标先撤出危险节点 | 保留原调查、开门、敌伤与未提取机会，按真实路线再来 | 撤退本身不是失败，不刷新来源 |
| 受伤／逃跑 | 用已有药物，原位合法休整，再接同敌；或走已发现且处理好的旁路 | 睡眠不回血；没有药不自动判死，已发生死亡不能改写 |
| 门卡丢在别处 | 真实取回，或用仍合法防火门方案 | 过去通过工作人员通道不等于永久免卡 |
| 安装料用于维修 | 尚存L3/C4备用来源可真实开柜搜索拾取 | 必须有路径、余量和未耗尽来源；没有自动退款或补发 |
| 部件／样本留在地面 | 本人回到原节点合法取回，跨夜不消失 | 不是安全提取、远程仓库或可复制第二份来源 |
| 所有合法替代耗尽、委托已不可完成 | 立即明确告知；仍活者按终局候选撤回H0或承受到期结果 | 不展示虚假成功目标，不把普通任务失败等同死亡 |
| 只完成一条成果线 | 在H0显式主动失败生还，如实交接部分成果 | 不发完整成功奖励，不抹去已恢复的设施 |
| 成果齐但人在H8或其他节点 | 沿真实路线到H0；Day1—6可按剩余窗口休整 | 不凭任务100%瞬移，Day7没有额外Day8路程 |

最终离开／终止时未真实携出物失去回收机会。放下关键物时须说明地点和终止后果；暂存可行不等于所有往返都值得。无需额外缓存柜才能跨夜留物，也不新增远程调货系统。
