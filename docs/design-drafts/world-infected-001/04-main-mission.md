# 04 主线任务：携回样本，恢复未完成的转运

> **DESIGN DRAFT — WORLD-DESIGN-001 / Draft v1.0。** 本文把完整世界的任务目标、实物、设施、信息和返回条件拆开，便于审查真实依赖。任务步骤名称不是新增 RunState、状态枚举或正式规则编号。新目的和具体内容是可审设计，不修改原医院任务。

## 主任务与故事结果

**DESIGN DRAFT：** 入场委托为：在第七日封锁窗口结束前，携回指定的密封病原样本箱，并恢复医院最后一条本地急救转运通道。样本是独立回收对象；本地升降机是让担架、设备和仍留在医院的人得以接驳的设施，不能解释成由普通电子元件制造跨世界通行能力。

玩家调查到的矛盾是：有人曾为阻止危险沿转运链进入安置点而断开支路，另一些人因此被困。解决办法是查明该隔离哪部分、该恢复哪部分，再用真实部件完成工作。故事不要求玩家选一份记录相信，也不把清空整区感染者作为委托。

**CONFIRMED INPUT（用户本轮澄清）：** 玩家在世界内连续驻留、所在地休整是真正采用的方向，细节由本设计任务展开。中途进出医院、物流、通信均不等于回到真正中枢或安全提取。

**CONFIRMED INPUT（正式边界）：** [DEC-046](../../05-design-decisions.md) 不允许固定次数签到或强制医院第一日；[DEC-047](../../05-design-decisions.md) 的已发生死亡优先、任务实物安全返回、提前完成不追加夜晚、无第八日是本稿保留的终局原则。原条款中的“稳定中枢显式成功”与本稿世界内返航入口之间的正式衔接须落文；本稿不新增可恢复的“已成功但仍探索”状态。

## 入场给足的任务信息

**DESIGN DRAFT：** 委托直接公开目标样本编号、本地设施型号、控制组件与匹配应急启动模块这两个功能缺口、安装需金属1＋电子1、最终返回接点在医院前室、最晚七日。它不公开精确敌人参数、每个货柜数量、未知内部路线或最优日期表。

这使物流与通信能独立开始：医院型号是真实业务信息，不是只有“先进入医院一次”才发放的签到凭证。玩家可先去物流核验组件，再去通信快核模块；也可先在通信查本地维护对照表匹配模块，之后去物流取得组件。先调查医院有信息和准备价值，却不是任务资格。

## 两条并行成果线

| 目标 | 真实前置 | 必须产生的结果 | 不算完成的行为 |
| --- | --- | --- | --- |
| 指定样本回收 | 到达冷藏室、处理实际阻断、合法提取与携带 | 同一个指定样本实体最终随玩家安全返航 | 看见箱子、日志有样本编号、交给当地NPC、留在地面 |
| 物流控制组件取得 | 找到组件、实地核验、解除运输固定及当前危险 | 组件真实进入玩家容器；来源不能再发第二份 | 货位调查、只解除卡件、从未取得但任务栏打勾 |
| 通信启动模块取得 | 医院型号＋通信现场维护表，或更直接的物流实物接口信息；合法到达与处理 | 匹配的模块真实进入容器 | 只去过通信、听见广播、知道型号、完成一次空访问 |
| 转运支路可用 | 到达物流支路柜、按现场证据隔离危险支路并恢复服务支路 | 可用于本地转运的真实供电与隔离结果 | 领取“供电任务完成”字条、整个街区万能通电 |
| 平台装接与验收 | 到达医院平台；供电成立；真实两部件＋金属1＋电子1可用 | 部件用于设备、材料消耗、本地转运功能实际恢复 | 曾经持有材料、把材料标为预留、缺模块但点完成 |
| 正式生还返航 | 实际到达医院前室、存活且无未结算战斗／强制危险；完整任务事实成立 | 完整安全返回与成功终止一致提交 | 完成装接后从平台瞬移、异地睡觉、任务文本显示100% |

**DESIGN DRAFT：** 样本线不作为组件、模块、供电、装接的前置。早取样能提前解决已知危险并获得来源证据；随身携带时承担箱子占格与负重，也可留在明确节点后付真实往返取回。晚取样减轻中途携带，却把护工与污染风险留到后段。两者都不额外加样本腐败、隐藏消失日期或NPC强制收箱。

**DESIGN DRAFT：** 最终安装在医院 **转运平台**，不是中枢台架、任务仓库或远程对话。单次装接验收候选12精力，真实消费控制组件、应急启动模块、金属1、电子1；未满足物品/位置/支路条件时拒绝且不消费。行动已经完整成立后，回执直接证明担架主通路接通与当地人员开始接驳，不要求再跑通信、酒店或周衡盖章。

```text
  ├─ 医院样本线 ─ 实体携带 ───────────────┐
  ├─ 物流现场核验 ─ 控制组件 ─────────┐  │
  │       └─ 可缩短通信匹配，不是唯一信息 ┤  │

  └─ 物流支路隔离／恢复 ────────────────┤  │
                 实际安装材料 ─────────┤  │
                                      ↓  │
                         医院平台装接验收 │
                                      └──┤
                                         ↓
                       真实抵达医院前室 → 正式生还返航
```

**DESIGN DRAFT：** 物流供电不依赖装好的医院控制组件；通信维护旁路是独立机械隔离，不依赖尚未拿到的启动模块；组件的解锁不需要先交样本。玩家可以先形成信息，再决定何时提取大件，但信息和物品不互相复制。

## 四类可混合路线

**ASSUMPTION：** 以下是区域承诺顺序与工作分配，不是完整战斗、背包或生还保证。每个箭头进入下一游戏日；途中和区内实际移动均付精力，角色在当晚真实休整点醒来。成本、补给和反例核算见 [预算](08-balance-budget.md)。

| 路线 | 主要区域序列 | 实际价值 | 主要代价与成立条件 |
| --- | --- | --- | --- |
| 初见调查 | H → L → C → H | 医院先取得医疗/权限/来源或样本，了解转运原因；物流接口帮助通信快速核验 | 至少一次医院回访，但不重开旧来源或护工；样本早取时占格更久 |
| 通信先行 | C → L → H | 先从维护表核对启动模块与当前消息，后取控制组件，最后合并样本/装接 | 通信现场核验比带物流接口更费精力；需确保末日医院工作和医疗可承担 |
| 物流先行 | L → C → H | 先取实物接口与食物材料，再去通信匹配；医院后置 | 组件占格更早；先搜前区还是深入取件，取决于工具、风险和携带 |
| 受损止损 | 如 H → L → C → L → C → C → H | 用不同日期准备医疗/材料、分段解决真实敌人、保持已完成工程 | 多一夜就有饱食/感染/流血成本；不靠睡眠回血、免费维修或来源刷新 |

**DESIGN DRAFT：** 主线完成后、期限前仍可以争取可选档案或交付，但正式返航后本次世界终止。不能“成功后继续捡东西”；也不为提高评分硬性要求做完支线。提前离开省掉尚未发生的夜晚，合理止损不天然降级。

## 可选任务：提供变化，不藏主线资格

| 支线 | 行动与真实成果 | 有用的时点 | 不做的后果 |
| --- | --- | --- | --- |
| 安置点医疗请求 | 在物流值班窗口交付绷带1＋消毒剂1，候选一次换口粮2；来源独立且实际转移 | 医疗富余而食物紧张时，换来更长恢复路线的空间 | 不封锁A休整、支路、组件、样本或返航；没有默认回血 |
| 维修员工单 | 对照物流固定件与现场工单，获得更省精力的拆卸方法 | 尚未卸件、工具选择不利时 | 仍可手动较慢完成；不是隐藏唯一装配授权 |
| 中止的转运记录 | 对照医院工单、物流封条或通信时戳中的两种独立证据，带回可解释档案 | 可与自然路线重合，不强迫每张纸都点开 | 不增加主线物理条件，不给予本稿未设计的永久战力 |
| 通信后勤捷径 | 发现记录并实际从内侧解除已有侧门 | 下一日去医院后勤更近；当日仍受主要区域承诺约束 | 常规C—H路保持可行，不形成通关死锁 |

**OPTION：** 医療换食物的报价与时点见 [事件包](06-event-pack.md)；未完成容量验证前，不把“交付后奖励自动入包”作为默认。正式设计应当一次核验双方真实转移结果；拒绝或取消不先扣药，拿不下时可以调整计划。

## 失败路线与可恢复问题

| 情境 | 玩家仍可做什么 | 何时真正失败 | 必须说明的信息 |
| --- | --- | --- | --- |
| 没拿到任务物就撤到安全节点 | 保留已完成调查/物理成果；下一日按实际路径再来 | 日期、生命或实际无解条件使其不可完成时 | 未提取来源还在，撤退不自动领任务物 |
| 战斗受损／逃跑 | 使用实际药品，休整后再接同一敌人，或采用仍合法的区域替代解 | 已提交死亡不能改写；没有药并不自动等于死亡 | 剩余危险与最后已知意图；睡眠不回HP |
| 失去门禁卡 | 用仍合法的防火门工具／手动方案 | 门卡丢失本身不判主线失败 | 门卡是权限实体，过去通过不等于永久授权 |
| 安装金属或电子用于维修 | 去尚未兑现的明确备用来源；若当前仍有材料可调整 | 全部合法来源与替代均耗尽、缺料不可逆时 | 预览当前安装差额；不能靠自动补发保底 |
| 部件已提取但留在地面 | 跨夜保留在实际节点，付往返精力回去取；不能远程安装 | 最终离开／世界终止仍未携出或使用，导致实际目标缺失时 | 地图仅标已知留置位置与最后观察；暂存不是安全提取或来源刷新 |
| 只完成样本或只完成转运 | 活着到医院前室显式选择失败生还返航，保留真实任务结果 | 本次委托不判完整成功 | 部分成果不是新可继续生命周期，也不假装设施未修过 |
| 任务都做完但人在平台 | 沿真实已知安全路线走到前室；必要时在期限内休整 | 已发生死亡或期限无合法返回不能由任务完成覆盖 | 剩余路程、精力与时间窗口，不显示虚假已成功 |

**DESIGN DRAFT：** 连续世界主稿保留未提取的原装置机会、玩家已携物，以及已揭示或主动放下的真实地面实体；过夜与跨区都不让物品凭空消失。地面物只在原节点，由实际到场的玩家合法取回，不能远程安装、消耗或安全提取。最终离开／终止世界时未携出物遗失；一次性来源永不补发第二份。放下关键物与最终返航需说明实际位置和后果，不能自动扔物或默默忘掉。此细节需明确局部替代旧 DEC-023/048 的结束探索语义，见 [决策队列](10-decision-queue.md)。

**OPTION：** 明确的有限缓存柜可以改善呈现和整理，但不是地面物跨夜保留的必需门槛。当前已允许真实战略暂存；它由固定一次性来源、往返精力与最终携出容量限制，不靠睡醒删除物品维持经济。不得用缓存柜新增远程仓库或反复领取库存。

## 成功、失败生还与死亡的终段

**DESIGN DRAFT：** 医院前室为本世界唯一已知异常返航接点。到达后读取真实任务成果与随身样本；活着且无待结算危险时，玩家显式执行正式返航。完整目标成立则走成功结果，目标不全时可以选择失败生还结果；两者都如实记录实际携出，不在深处传送、不追回丢失物、不生成第二份样本。

**DESIGN DRAFT：** 精力0但已在合格返航点，允许返航操作，不要求为了按终局按钮多睡一晚；精力0仍在别处不能免费移动到前室。返航不是新探索、不回血、不修装备、不追加尚未发生的夜晚。伤势、感染与未结算暴露以实际终态保留，不能“出了世界就算治好”。

**BLOCKING DECISION（正式落文，不重开连续驻留方向）：** 本地返航、返回后的成功终止及真正中枢衔接，需要在实施前说明怎样局部替代 DEC-047 旧入口而保持唯一终止。第七日异地未完成、失败生还惩罚、角色家底和跨任务保留的具体组合以 [集中队列](10-decision-queue.md) 为准；这里不创造新的 RunState，不把任务失败偷换成角色死亡。

**CONFIRMED INPUT（正式保留）：** 第七日仍可正常行动并提前成功，不补过夜，不产生第八日自由探索。已经发生的生命归零或正式感染终末始终优先，成功清单不能复活角色。

## 附件思想的采用与保留

**DESIGN DRAFT：** 本稿采用外部叙事输入 `infection-world-narrative-proposal-v0.5.md` §2—8、15 的“样本独立携回＋恢复当地转运”、真实设备前置、非强制医院先访、NPC可选与书面替代。它在用户本轮确定的连续驻留方向下重组为三个区域；不把此前讨论稿中的历史四日算例当新路线结论。

**OPTION：** 当地NPC永久收取样本、再以交付事实代替最终随身样本，是附件明确保留的另一任务模型，**不是 v0.5 当前推荐，也不是本稿主方案**。采用时必须重写实物回收与结局条件，不能一边交箱一边在返航时复制箱子。

**OPTION：** 酒店、独立供电所、更多医院后勤房间保留为后续内容展开；当前NPC医疗支线与物流支路柜已经承接其必要职责。它们不因方向可讨论就自动成为额外首版必做地图。
