## 4. 持续库存、留置与备料

**DESIGN DRAFT：**真正中枢只在任务间可达。过夜保留实际装备、背包、快捷位实体、数量、状态与所在位置，没有自动转仓、整理或翻新。

来源正式揭示即兑现。所有已揭示或主动放下的真实物品留在原节点，跨夜及区域转移保留；只有实际到场才能拾取，不远程调用、不复制、不自动入库。世界最终离开或Run终止时未携出的物品才遗失。未揭示来源、未提取原装置机会仍保留；提取后放下的任务实体只在其实际位置，不回到原装置再生成。该语义局部替代旧DEC-023/048的结束探索失物，必须进入新版本正式覆盖。

**OPTION：**具名固定储物柜可另设计明确容量、位置、保护或存取差异；普通原地留置已有实体持续，不因此增加免费远程仓库。NPC交付也不是可任意取回的寄存。

**DESIGN DRAFT：**安装料可做随身“预留用途”提示，不改变容器、格子、重量或实体所有权；玩家可解除预留使用，后果显示主线缺料。不自动锁死或复制库存。讨论中“存入任务区可取回”的真实备料柜若采用，须在[10](10-decision-queue.md)指定物理位置和容器。

装接实际消耗控制组件、启动模块、金属1、电子1，形成转运设施物理成果；样本仍须实际持有并最终携出。部件消费与成果一次提交，不留下可重复装接的原件。最终正常返航中样本移交委托方，不继续作为玩家可用家底；失败任务专件与权限也不跨任务复用。完整去向以[终局候选](reviews/endgame-candidates-v1.1.md)为唯一细则。

## 7. 防无限搜集与雪球

- 一次性来源绑定同Run/规则版本/地点/来源；休整、日期、刷新、调查顺序不重抽。
- 击败只解除危险，不自动发战利品；已解卡件不重复收费，也不能换工具重复拆出材料。
- 实体始终占真实容器；任务件不能同时存在背包、任务栏和已安装装置。
- 单精力、实际移动、食物和日期形成真实成本；同日可合并跨区工作，不会因短日免费回血、补工具或刷新来源。
- 允许浪费，提前说明后果；主线材料主动预留不强制保护。所有真实替代耗尽才明确阻塞，不拿“推荐路线不通”当全局失败。
- 有限NPC交换必须真实交付且与事件共用来源账；不把每种余料都无限兑换成任意缺项。
- 正常生还携出的普通物按实际数量和损耗延续、死亡失去全部角色可用家底，是已确认方向待落文；不重新投票。具体转移和罚则仍按下节候选，不在本章创建Profile或保存结构。

### 7.1 终局清算、身体服务与下一次准备

**Owner已确认方向／本轮Draft细则。** [当前终局稿](reviews/endgame-candidates-v1.1.md#four-endings)推荐H0正常成功或主动失败的实际返航，异地末日按本次任务候选处理。HP0才进入统一角色死亡；感染高阶段但尚活可合法返回并付费处理。正常合法返回不追加未来一晚，返回本身保留真实健康。

积分归角色。完整成功一次入账120；失败／部分成果0收入，失败扣最多30积分。**本次失败新取得而未消耗的普通物回收、旧携入剩余物和旧中枢库存保留**，作为显式待审的失败处罚，不能误称为Owner已经批准的携出范围。它替代旧最多1粮＋1金属罚，不叠加；期限异地不再额外全丢旧背包和快捷位。任务实体、权限、样本交付和地面遗留以终局稿为准。来源需跟随真实单位，混合堆叠、换槽或消费旧物后补新物不能洗成旧资产。

实际生还结算后，玩家先拥有本次合法积分，才显式选择20／40／80的身体服务；报价按病因，不按每一滴HP或钱包。本期身体服务清HP损失、流血、活动伤势、感染与暴露，不改饱食、精力、装备、库存和当日额度；详见[11覆盖表](11-points-hub-recovery.md#body-recovery)。不满额支付不会半扣费、先免费治或直接判死。

正常返航后的静态中枢窗口可先使用真实药食／服务；接下一任务前必须显式执行一次角色日休整。先处理流血、感染与饱食生命后果，活着才推进真实角色日、更新药效／日次数／标志额度并将E设100；任务Day1不冒充人生从未经过昨日。期限已经完成同一角色日推进者不重复交一夜。没有免费HP、自然消伤、装备翻新或初始套装重复赠送，见[11低余额与日期边界](11-points-hub-recovery.md#low-balance)。

### 7.2 收益、供给与仍未封闭的失败收益

普通 `normal_five` 返回HP4、感染20、饱食4、管15／外套7／撬7，带出粮4／绷2／金1／布1／电池1；当次0→120，治身体40，再买绷带18，余额62、绷带3。用金1修管到30、布1修外套到12后，金和布各0、撬仍7；维护不额外收费也不创造材料。下一晚可实吃粮1使饱食4→6→4，粮余3。完整来源、逐行动和联合接续见[08](08-balance-budget.md)。

高损耗的 `damaged_split_five` 从HP8独立受损输入出发，373E／7日后返回HP2、感染25、饱食2，消费3绷和4粮，其中旧初始绷带1已真实用掉；它只需40服务，不是80重病路线。HP1／感染130／原余额0的合法成功可先领120再付80余40、买绷后余22，是另列独立末端条件，不证明重病全程前缀。身体费用不按HP逐滴跳档，净积分为正也不意味着旧药／材料／装备被补回。范围比较见[11](11-points-hub-recovery.md)，未来急救包45不计当前所得。

连续10次成功采用额外搜索既有H_hall取金1的**补给型路线**，每程281E、Day3余12E、带出金2；九段真实准备消费18金和9布修管／撬／外套，并在过夜后吃18粮。每次120收入−40治疗，最后只买一次18绷带，期末782积分，HP12／感染0／饱食4／角色日30，管15／外套7／撬7；银行粮22、绷12、金2、布1、电池10。成功→失败→成功同样继承实物，期末112积分。不能用原269E单程免费重置工具或反复仅吃首程1粮却每次以饱食6开局；材料和逐次账见[11连续经济](11-points-hub-recovery.md#continuous-economy)及08。

**供给边界。** 同一终止任务不能重入或重新领奖；不同新委托是否、何时提供，仍是内容供给政策。联合压力夹具明确授予10个同规则但不同执行身份的新委托，不靠“同一来源只有一次”回避跨任务循环。其新世界来源合法重建，角色的健康、日历、家底和日额度真实继承；首期没有已经实现的十个委托或第二世界。

**真实风险。** 20E取绷带后失败在新物回收下不能囤出绷带，但先用新绷带回血再失败仍保留HP收益；先用新金属修旧装备亦同。基线饱食耗尽后绷带+1可能抵消每夜饥饿−1，维持健康而不增长余额和库存；[07生存专长候选](07-enemy-continuity.md#minimal-specialties)若采用任务内+2，甚至可能逐轮净回复HP，须另列对照，不能以无专长主账覆盖。实际10次20E失败共9个中枢夜：HP12起点仅取物终为HP5，新绷10全回收；先自用7枚则终为HP12，只回收3枚；两者积分0、饱食0、角色日10，旧绷1均仍在。HP4起点每次用新绷，基线+1末HP7、生存OPTION+2末HP12，均已消费10枚。十次成功与失败因此必须同时比较积分、身体、饱食、装备、物资、角色日和执行次数；不能把残留收益标为已封闭。

主推荐公开保留该风险供Owner判断。重复委托收费12或限制任务供给是[11中的替代候选](11-points-hub-recovery.md#failure-policy)：会阻断0积分连续进入或消耗有限机会，但可能导致唯一内容版的活人无法再出发／无法继续游玩；不是免费且无损的防刷补丁，本期未默认启用。
