**DESIGN DRAFT：** 本新世界在实际节点休整、原地醒来，不再把日变更自动解释为新Scene入口重置。取消每日区域门禁后，同日可沿合法路线处理多个地区，切区次数不建立或重置另一份敌人。保留上述敌人物理连续性；日期、行动额度与知识承接另需正式落文。已经结束的战斗和当前尚未结束的战斗必须区分：重载未结束战斗恢复其原CTB和临时事实，不能借“新一天”清除不利时序。

## 3. 特殊敌人候选

**OPTION：** “导流区重症感染者”可作为未来物流维修支路后的可选危险，具有明显的长准备扑撞与短暂暴露窗口；仍是一个敌人实体，不加入召唤、站位、断肢或多目标。它只护守额外资料/普通补给，不能护守唯一安装料或三件主任务实物。

当前包不把它加入七日最低路线、不另发一整套奖励，暂不赋完整参数或承诺已平衡。若加入，须先声明来源、持续身份、两招意图、首次/再接战、实际费用与可绕开路径，并重新核算医疗。普通护工换颜色不能构成特殊敌人设计；必要性不足时不加入。

**OPTION：** 通信检修间的物理隔离旁路是环境解，不是第四种敌人。玩家隔离某条走廊并从C4到C3，检修员仍活在C2，保留原生命和意图；以后主动走入C2仍触发同一个危险。旁路不构成“已击败”，不触发战利品，也不把未访问的区域自动标为安全。

## 4. 已解决与未解决危险

| 实际世界事实 | 后续处理 | 玩家可知投影 |
|---|---|---|
| 正式战斗中敌人失去能力 | 同Run不回血、不复活、不补替身；解除该具体阻挡 | 见证者能记住“该护工已失能”，不是“医院永久安全” |
| 已接战后逃跑，敌人仍活 | 保留真实生命、选定下一意图、循环进度和已消费风险位置 | 记录最后观察到的生命阶段/意图；不显示精确HP或远程更新 |
| 只是到附近，未进入战斗 | 不算曾交战，不套再接战起点 | 只给当时可见声音、痕迹和危险范围 |
| 成功物理隔离/绕过 | 保留隔离设施成果；敌人仍在且危险未解除 | 区分“此路线可通”与“敌人已死” |
| 危险已解除但来源未搜 | 保留搜索机会，搜索仍需精力 | 已知危险解除不自动知道柜中内容 |
| 门/固定件已真实打开 | 不重复收费/磨损/拆卸产物 | 可记住物理成果；权限门仍查当前实体凭证 |
| 供电支路已隔离恢复 | 保留明确设施效果；不新造感染者迁徙 | 可观察相关设施改变，不把全世界状态全盘告知 |

敌人没有离线行动、迁移、按日增强、夜袭、无限尸体搜刮或再占据；这些若以后有价值须另设内容，不能作为“世界会变化”的默认附赠。世界变化也可以是玩家实际完成的工程与减少的危险。

## 5. 再接战、次数与战斗精力

**CONFIRMED INPUT：** DEC-048列名三个敌人的再接战为玩家0、敌人50，保留已选下一意图；清除已结束战斗的绝对CTB、临时延后、防御与逃跑准备。50不是所有未来敌人的通用常量。立即进入后逃跑也算曾交战，不能无限重取首访慢起手。

**DESIGN DRAFT：** 连续驻留下金属管原“每次探索一次”以一次合法游戏日的探索额度承接：成功休整进入次日才建立下一次额度；同日转移、换节点、再接战、打开界面或刷新都不补。它不代表每场战斗刷新，也不让失败日结算发新额度。该映射涉及旧生命周期语义，应列入正式覆盖与分段试玩复查。

**DESIGN DRAFT：** 遭遇胜利/逃跑结束时，一次收取 `max(6, 4×ceil(实际CTB经过量/100))` 精力并最低截零；战斗中不再逐CTB扣精力，不保留第二场景时间预算。伤害、流血、耐久、药物仍按真正行动发生，CTB不是免费时钟。

从正精力发起合法移动而进入危险，移动后变0也要完成已进入的战斗/逃跑，不被精力锁住攻击或休整跳过。0时不能主动发起新的探索/入战；无额外精力债、强制返程损血或撤退税。小数倍率和UI批处理不能把多个移动变成一次超大最后行动。

公式是本包工作建议，可调区间见[08](08-balance-budget.md)。低成本0CTB击倒仍收最低6，无法用残血敌人生成精力或物资。

## 6. 物理连续性与玩家已知分离

物理敌人、门、来源、供电成果只有一份可变真相；玩家知识是正式观察的记录和当前可见投影。未观察到的改变不自动推送精确坐标、HP或后续行动；日志保留事实不等于获取整图导航。

连续驻留保留实际当前位置，已经合法发现的同世界路线如何跨日使用由[02](02-seven-day-structure.md)统一声明；这与旧DEC-045/048的新Scene入口知识边界存在局部差异，不能由UI看到区域名字后遍历完整图补全。任何路线在地图显示或用于移动前必须具有合法发现来源；“曾听到机房存在”不等于知道隔离旁路。

| 查询/命令用途 | 可读事实 | 不可执行的隐藏副作用 |
|---|---|---|
| 查看意图与相对时序 | 当前公开意图、可知结果 | 不推进敌人、重抽风险或改变CTB |
| 查看已知地点 | 已确认危险解除/已用来源/合法路线 | 不领物、不补全未知节点 |
| 继续正式战斗 | 唯一敌人事实、当前角色、绑定内容 | 不从历史摘要另造满血敌人 |
| 休整/转移 | 当前稳定事实及明确持续规则 | 不自动消费新的敌人风险、刷新来源或治伤 |

## 7. 保存和责任约束

本节为职责分析，不设计代码接口。战斗拥有一次接战的行动顺序与临时事实；持续世界拥有具名对象跨窗口需要保留的实际成果；物品体系拥有实体转移；知识体系拥有合法发现；日期只触发声明的跨日协作。谁在稳定时点拥有可变事实须唯一，不能由两个模块各改一份敌人生命。

一次行动的伤害、风险序列消费、失能、来源开放与成本形成同一个稳定结果，不等到过夜才第一次记住。Return Ledger仅记录实际世界返回，不当作每日休整日志或通用世界状态；历史战报不成为当前敌人/库存的另一个主人。

严格恢复将来必须拒绝：已失能却有可战副本、同来源重复产物、同实体在两容器、风险回退、未完成战斗被当成已逃跑、死亡被睡眠恢复。错误不通过静默回血、补齐物资或重抽修复。

| 用例 | 预期 | 当前证据 |
|---|---|---|
| C首战击至6生命、下一意图挥击后逃跑 | 次日仍6、仍该意图，再接战0/50 | [08](08-balance-budget.md)手工CTB接续；非生产执行 |
| 同日反复进出 | 不恢复蓄力、HP、来源或首访起点 | 规格预期，NOT RUN |
| 跨日已击败L后取未开料架 | 只付真实移动/开料架，旧敌不重生 | 规格预期，NOT RUN |
| C旁路隔离后回走C2 | 原敌仍危险，旁路成果不等于失能 | 规格预期，NOT RUN |
| 敌人将死但玩家行动后流血致死 | 玩家死亡优先，无成功携出 | 正式边界+新世界组合待验证 |
| 已解决危险恰好邻接A级休整点 | 可在合法点休整，不自动回血或免费返程 | 规格预期，NOT RUN |
| 分段消耗六夜仍未满足主线 | 不因打了多次而给完成；第七日不生第八日 | 规格预期，NOT RUN |

后续试玩至少对照一次完成、被迫止损、主动分段和反复分段。衡量公开信息是否足够、风险是否可理解、来回操作是否枯燥；不以增加敌人回血、撤退罚款或分段次数上限偷偷修复。当前无完整胜率、全工具覆盖或Owner体验通过结论。


**终局衔接：** 已完成动作后的玩家死亡终局优先于战斗胜利、任务返航和召回；同动作已经造成的敌人损伤仍可如实进入只读历史，不能以胜利结果覆盖死亡。末日期限不能中断当前战斗触发救援，只从稳定结果进入期限流程。召回、失败实物罚和感染终末角色后果均只在[唯一终局稿](reviews/endgame-candidates-v1.1.md)作为待审候选，不从敌人持续规则自动推出。

## 9. 三专长最小候选，不领取主账优惠

**CONFIRMED INPUT：** DEC-005/041要求完整世界补回侦察、工程、生存，局内不能更换，不得锁主线。以下为 **OPTION / ASSUMPTION**，不是医院生产功能或已经通过的平衡值。

| 专长 | 具体最小候选收益 | 真实条件与普通替代 | 不改变什么 |
|---|---|---|---|
| 侦察 | C1完整匹配6E→4E；已有物流实物接口时快核4E→3E | 真实在C1且表可查、该事实尚未完成；无专长仍按6/4E完成；已有结果不重复收费 | 不在C3远程匹配、不泄露未知地图/敌HP、不复制模块 |
| 工程 | L2组件运输固定件的手动卸紧14E→10E | 在L2、卡件未解且当前危险允许作业；撬棍仍按6E＋耐久1，普通手动14E仍合法 | 不免核验、提取、危险或实物；工单已给10E时不再叠到6E；不重复产物 |
| 生存 | 当前任务内绷带恢复2HP，基础为1HP，最多到12 | 消费实际绷带；止血/处理合格伤口不变；战斗仍须快捷位与原CTB；任务间中枢用基础1HP | 不降感染、不自动清伤势、不回精力，不把0单位药变1单位 |

侦察改善指定信息操作效率，工程给指定障碍更省力的普通解，生存提高现有药物利用。不新增全局百分比、主动技能或永久属性。任务前显式选定一次，局内不换；任务间医疗不套用已结束任务专长，也不能换专长补药。

主账不领取这些优惠。局部量级可复核：C1完整匹配省2E；无撬棍L2卸件省4E但不叠工单；绷带有恢复空间时额外+1HP。省精力可能改变最后行动归零和休整位置，不能只从整日总数减2就声称路径通过。三专长×三工具、伤口分支及新健康路径仍需单列验证，本轮未穷举。
