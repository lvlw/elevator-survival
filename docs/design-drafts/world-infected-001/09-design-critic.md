# 09 Design Critic：补给、出发、失败与证据边界

> **DESIGN DRAFT — WORLD-DESIGN-003 / Draft v1.3。** 本页记录本轮针对实际文稿和共同有限模型的批评、修订及仍未关闭的产品取舍。独立审查与模型通过不等于Owner批准、生产验收或可玩性证明。旧002自检原文固定在起始SHA，不改写历史发现。

## 1. 前轮实文件审查怎样进入本轮

[原审查](reviews/input-196d4bf/inputs/review-196d4bf/AUD-196d4bf-world-design-002-review-v1.0.md)是29项选段／独立模型观察，28符合预期、1实际不符，不是旧171项完整仓库复跑。

**F-01：50E物流安全补给。** 旧批评只重视20E药房，却漏了手动开L1柜的绷带＋口粮路径。往返14＋14，手动14、搜索8，共50；无战斗或撬损，不需要新敌人或假定随机粮。旧没收也无法倒扣已经吃粮／用药的效果。v1.3把真实边、开柜、来源、拾取、使用、返回与下一launch接入同一perform，供给仍显式假设十份不同执行。不能把结果称漏洞已封闭：允许退却收益与机械循环风险同时存在。

**F-02：死亡错误追改历史。** 旧terminal_death把除consumed／installed外的单位都改lost，连早已移交的sample和已回收新物也被改写。本轮预期是只清当前仍可用的bank／pack／快捷及适当当前地面，已交付、部分交付、已回收、已扣罚、已消费、已安装等终结处置不变。不是只过滤两个名字：还要真实上一任务S或旧回收F→下一任务／衔接死亡，保存前结果不变，重复死亡和重看也不改分类。修的是设计检查器，未运行生产死亡代码。

**F1a／F1b保留。** 给定CTB轨迹若提高伤害后敌人在280或0已失能，后续预写动作须拒绝；首次慢起手不能借再接战身份重用。拒绝失效人工轨迹不等于游戏禁止早杀。旧171项87正例／83应拒绝／1未支持按实际ID逐项迁移；不能删负例换绿。

## 3. 实际交叉审查及范围内修订

三个专项角色分别编写经济／补给、生命周期／终局和有限证据；根会话再读实际文件、输入和函数，交叉批评后整合。不是把作者的“已完成”直接当验收。

| 实际发现 | 原位置／原因 | 修订 |
| --- | --- | --- |
| 目录方向分类过强 | 10把粮金默认资格与医疗解锁放“已确认／暂定”表；原方向明说“主线推荐、本轮设计默认” | 从已定表移出，在授权内Draft表显式标记。正常launch暂定编排与商品默认不再混级 |
| 来源消费仍固定新物优先 | 根实读consume发现新主案也沿用旧回收的选择排序，与11收窄该规则冲突 | 共同模型按主案稳定实体ID、旧回收案新物优先区分，并保存对应正例；守住单位身份／实际消费，不用同类数量差值重造旧物 |
| 身体服务严重阈值仍硬编码 | 根实读therapy_cost中的90；任务要求价格与症状阈值统一版本化 | 已移至severe_infection_min参数，并以100阈值夹具实际执行；不把改文档当验证 |
| 酒店交换未验证实际奖励容器 | 独立实读npc_trade先收药、把粮放地面，满包且药在快捷位时可出现付药后接收失败，与04／06合同冲突 | 共同模型改为合法接收后一次交付与奖励；24格满包拒绝、22格可接真实转移及正常22E比較均有独立预期 |

## 4. 失败动机的评价不能只用积分

在相同十份独立委托机会下，完整成功挣积分并开放医疗，安全20E／50E失败则可能以少量探索维护身体或积累普通补给。P0的实际失败罚0，未拿120不是被扣120；旧回收也留不住已经转化的HP／饱食／耐久。把所有物品按不存在的卖价折现会掩盖这一差异。

轻罚主案降低诚实止损的损失与解释成本，代价是物流前柜可能成为最理性而重复的整备方式。感染者的日级恶化使这一路线并非普遍安全；生存OPTION强化绷带又可能让它更强。成功账更富不等于低风险刷取不诱人。是否接受这段玩法、调整有限内容供给或引入别的代价是Owner取舍，不能靠临时改库存、添怪、禁止重试或接取费把例子做绿。

所有对比标明相同观察点。已返回、已治、已购、已维护、已衔接与刚进入下一世界不同；未执行的末次衔接不先扣伤，但若继续会面临的后果须保留。实际物资和装备没有因文稿说“恢复”就变满；服务不包维护与粮。默认开布／电能减少基础配装回刷需求，工具箱电子仍未售，专业连续性不能从撬棍主账推定。
