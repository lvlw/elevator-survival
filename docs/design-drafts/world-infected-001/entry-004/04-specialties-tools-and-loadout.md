# D04：三专长、工具箱与首次准备

DESIGN DRAFT / 待Owner采纳；承接[旧专长最小稿](../07-enemy-continuity.md#minimal-specialties)，不把旧ASSUMPTION当生产规则。数值统一见[参数](parameter-candidate.json)，不增加等级、词条、职业树或另一份委托。

## 初次配装与锁定

推荐真实初始发放：金属管、厚外套、三选一工具（撬棍/手电/工具箱），各`capacity.*`；初始绷带`unit`进入快捷槽。其余库存为空，无初始口粮或隐性电子。工具箱由这次真实选择发放，不能开始后免费换工具或从名称创建另一件。现有物品ID见content-candidate的映射及医院items定义；初始锚与世界来源锚严格区分。

专长在本次实际出发前选定，当前驻留和读档锁定，保存在角色当前执行的受控选择记录；C/B验证选择与能力效果一致，不从界面临时注入。跨未来委托能否改选继续待审，不为演示另造任务。

背包`grid`与`physical.*`定义格位/重量/堆叠；已装备槽和快捷槽依现有计重边界，不拿地面或中枢家底远程支付。任务大件相互占格，先明确旋转/放置再扣物；没有后台自动压缩、默认腾包或暗送容量。`load.bands`沿用旧预算候选，不能误用旧医院重量表替代新世界候选。

## 九组合：局部证据，不是九套通关

专长本体：侦察仅C1核对按`verify.scout.*`，不白送未知位置/来源；工程L2手工修复按`fix.method`，与周衡方法只选一次，不加倍折扣；生存本委托首次合格绷带用`survival.hp`，替换`bandage.hp`而非相加，后续普通药效、HP上限和目标资格不变。

| 专长×工具 | 实际选择影响／资源区别 | 普通替代与不能叠加 |
|---|---|---|
| 侦察×撬 | C1核对省E，同时H1/L柜/C4旁路可花撬耐久开 | 无撬走门卡/手工；侦察不免危险或给组件 |
| 侦察×手电 | C1知识处理优惠；H1/H2/H3以电换`search.lit`，不改固定产出 | 电尽走`search.dark`；不把照明再当侦察折扣 |
| 侦察×工具箱 | C1优惠与H1专业电子各自生效，电子能维护或留安装 | 无专业电子去L3/C4真取；不在已开门后追领 |
| 工程×撬 | L2可比较撬耐久路径与工程手工路径，后者省耐久但仍耗E | 普通人可学周衡方法；工程与方法不叠加，撬成本不再减 |
| 工程×手电 | 照明省搜索E，L2修復无需为同一折扣绕访L5 | 黑暗/普通手工仍能做；工程不能免费充电 |
| 工程×工具箱 | H1取得专业电子并维护，L2工程手工，L3补安装电子 | 两种能力不同事务；工具箱不自动造组件。单列完整条件路线 |
| 生存×撬 | 可在医院分段退却后首绷多恢复，开柜/旁路仍真耗撬 | 普通绷带仍止血；休整不刷新首绷，修撬不回血 |
| 生存×手电 | 首绷保留生还余量；手电省搜索E但不降低感染精值 | 普通绷带+黑暗路；药效与照明不叠加成万能风险豁免 |
| 生存×工具箱 | 首绷缓和初战损失；电子在专业续航/安装间选择 | 其他普通修复/门卡路径仍在；生存不减专业配方 |

有限用例`nine-专长-工具`检查专长结果，`tool-专长-工具`检查对应工具的真实E/资源变化；这两个局部投影共同覆盖九组合的选择后果。只有四条固定路线，三种专长/三工具不是全组合胜率保证。特别是手电电池仍须带得下、取得及充电，E0不能开始付费充电；武器耗尽和严重伤病可使路线失败。

## 工具箱线路与维护竞争

`route-toolbox`从真实初始工具箱入场，在H1支付`door.toolbox`、耗`wear.tool`，拾取一次电子，然后实际用金属+电子维修工具箱。收益不是抽象“专业优势”：消防门已开、电子已经消费、工具箱资源回升。后续物流来源还须另取金属和电子，携两件任务物到H8安装；若省略L3且余电子不足，安装必须拒绝。

工具箱H1新E值是本轮补缺，不把旧30 Scene Time直接重命名；主推荐处于撬门与手工之间并附电子收益，代价是专业维护依赖电子。替代更便宜或更贵都需Owner后续体验再评，本轮不搜索参数。

## 体验边界

初始配装无食物不等于保证初见安全；物流前柜可获粮但有路线和超余额边界。提示须说明已知目的地、剩余E、携带空间与可知伤病，不能要求玩家读内部攻略。真正首次玩家能否理解留样、安装与撤退，应在低资产UI完成后按[门槛](07-playable-and-release-gates.md)观察。当前未执行人工试玩。
