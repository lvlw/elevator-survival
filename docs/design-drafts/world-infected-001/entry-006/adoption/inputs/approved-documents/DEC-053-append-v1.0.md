### E01. 适用版本与唯一事实

只适用于《封锁区·未完成的转运》新连续驻留版本。DEC-049—052的具体委托、不重接、单精力、身体周期、四终局、真实资产、来源与HP0死亡制继续生效；旧医院的规则、公开感染阶段、入口与存档语义不倒改。

病程提示是从已提交身体事实派生的只读知识，不是新的状态所有者、症状机制、治疗或死亡条件。查询、Hover、Focus、刷新显示不推进病程、日额、revision、时间、随机或委托。

允许普通玩家查询显示当前病程负担粗档。唯一分段来源为[已批准核心试用配置](content/infected-residence-core-test-config-v0.1.json)的`config.health.infection_damage`，不是`infection_stages`增长表。未来实现须引用对应版本的正式配置／同源纯owner，禁止UI复制一套阈值。

| 当前所属配置段（技术定位） | 玩家标签 |
| --- | --- |
| 第1段；当前配置0≤p<60 | 未达病程损耗档 |
| 第2段；当前配置60≤p<90 | 低病程负担 |
| 第3段；当前配置90≤p<120 | 中病程负担 |

当前档不是下一次日结答案；真实周期仍会依正式顺序处理流血、增长／暴露／抑制、感染损耗及饥饿等。不得因此公开精确进展、潜藏暴露数量、连续百分比、内部增长表、未来精确扣血或隐藏日结死亡预测。

### E03. D1：隐藏医疗与同档非干涉保持

消毒剂／抑制剂隐藏目标的Preview继续`unknown`；本条不把粗档变成目标资格探测器、自动用药条件或新增可用按钮差异。
