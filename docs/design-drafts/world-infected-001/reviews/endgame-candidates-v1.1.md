## 2. 所有结尾的先后边界

1. 先完成当前正式动作的伤害、流血、暴露及物资消费。实际生命已为0立即走死亡结尾；同动作完成任务不能撤销结果。
2. 感染在正式检查点已达终末时走感染终末结尾；返回和新任务不能重置。未结算暴露或下一晚可能死亡不能提前算成已经发生的硬失败。
3. 无活动战斗、未完成返程或待立即结算危险时，才可正常返航或确认期限。持续流血本身不锁死所有非战斗操作，仍按真实检查点产生后果。
4. 查询、取消只展示实际缺项和已声明代价，不消耗、不终止、不重抽。确认后锁定同次事实，不能插入用药、整理或换装备改变本次结局。
5. 世界终止摘要只读；结束后不能探索、提取、取回地面物。下一任务不重新打开这个世界。

**OPTION：真正不可完成的委托。** 唯一关键物确已永久销毁且无合法替代时，立即明确说明委托失败；不继续展示可成功的假目标。仍活着者只保留在本世界有限期限内沿合法路径撤到H0或接受期限结果的出路，不能补发物品或重新取得成功资格。这需要局部调整旧DEC-028的即时Run终止边界，不以既有类型名掩盖候选差异；没有新增期限或可重复领取的任务。

## 4. 有上限的失败实物罚

**OPTION / ASSUMPTION：** 失败生还时中枢收取任务损失补偿：**压缩口粮最多1单位＋金属零件最多1单位**。这是事先公开的结果罚，不解释成食物提供跨界能量，不新增货币、交易或欠债。

- 正常失败先把真正携出的普通物与同角色中枢旧存货合账，再分别扣 `min(1,实际口粮)`、`min(1,实际金属)`。旧家底可以承担支出。
- 到期召回先落实携行损失，再从剩余真实家底扣；遗失包内食物不算已经缴罚的物资。
- 不足只扣现存，不以救命药、装备或其他材料折价替代，不生成负数或未来债务。两类均0则额外罚0；本次实际消耗、无完整成功奖励及失物仍在，不能说所有失败都固定罚满。
- 预览列明扣除的具体真实单位；选择与消费一次完成，不能删除后从历史重新生成同名物。
- 罚则不直接改生命、饱食、感染或耐久；扣一份食物是失去将来的使用机会，不是立即饥饿伤害。
- 仅失败生还终止收一次。普通撤退、战斗逃跑和分段突破不收，保留[DEC-008](../../../05-design-decisions.md)的合理撤退边界。

量级刻意有限，不按仓库比例吞掉家底。富裕角色可能觉得很轻，初期角色会损失后续补给与维修机会；需体验比较，不以隐藏涨价弥补。

## 6. 期限流程与主动止损比较

**OPTION：** 第7日仍可探索、用携带自救品和真实返H0。E0异地可确认期限结果，不能再移动。现实时间和关页面不推进截止；无Day8自由探索或“第八日回家专用路程”。

期限确认按普通跨日已接入阶段处理：①未止血扣2HP；②感染依现有阶段基础增长及未结算暴露增加，达到120终末；③饱食减2至最低0，结果0—1扣HP1。某阶段硬失败即停止后续。生还才结束当日临时药效并召回；没有下日，因此不建Day8、下日精力、蓄力额度或医疗次数。它是最后一日的已声明危险检查，不能先召回再挑选是否承受。

这不为提前正常返航补夜。普通跨日主稿已排除回血、治伤和维修，期限也无这些恢复；健康、物品与终止一次提交，不保存只扣饱食但没处理感染的半状态。

**OPTION：异常召回包装。** 入场任务联系在窗口关闭时只能拖回仍可生还者及少数附着装备，背包、快捷物和任务箱不能通过。本世界一次终局事件，无召回道具、充能、战斗中呼叫、提前异地按钮或重复操作。装备槽仍按真实类别和位置校验，不能把箱子改名塞进武器槽；确认快照后不得临时换槽。

| 选择 | 保住什么 | 成本和公开风险 |
|---|---|---|
| 尚可走路时主动返H0失败 | 普通包/快捷/装备均可真实带出；无追加夜晚 | 路程精力与真实沿途危险，加终止实物罚 |
| 拖至期限召回 | 健康检查后仍活才保人物和三槽 | 一次日级后果、全部包/快捷遗失、同一有限罚、无成功或收藏安全提取 |
| 已在H0却选择期限 | 也不会得到更优运输待遇 | 同样日级风险与失物；预览可取消后选择正常返航 |
| 主线完成人在深处 | 设施成果保留历史 | 未正式返航仍失败，样本随包遗失，不由勾选复活或成功 |

空包、健康且无可罚家底者可能穿好装备后等待召回，借此省掉危险返程。主案公开允许这一失败止损优势，不虚构它总比主动走回差；它无法运回包内收益或样本，没有新开局物资赠送。**这种选择是否过度削弱返程体验是Owner核心取舍**，不能说已经消除全部免费旅行动机。

**仅一处分叉备选（OPTION）：** 期限召回只保角色，三槽装备也遗失；其余日级顺序、有限罚和下一阶段相同。空包仍损装备，但初期玩家更可能徒手再出发。推荐先审主案，备用不同时叠加比例扣仓、随机丢物或生命税。两者都不得召回实际死亡者。

## 7. 回中枢与下一次出发的最小接续

**OPTION：** 生还后在真正中枢整备，本世界只读。角色生命、流血、伤势、饱食、感染、未结算暴露、药效/日次数及损耗原样承接。停留不按现实时间恶化，不免费治愈、维修、充能或补包。

1. 可查看、整理真实家底，使用已有医疗/食物，选择下一任务。绷带实耗1、+1HP且处理合格伤口；急救包实耗1、+4且移除一个合格轻伤；消毒剂只减未结算暴露，抑制剂不降低既成感染。基础职责见[物品](../../../content/items.md)，没有全治疗服务。
2. 失败罚在返回交接中先完成；整备不能回到罚前抢先使用将扣物。取消下次出发也不返还已经消费的药。
3. 没有新增满血出发门槛。仍活且未终末者可以带伤、空仓或破损装备出发；最低临时攻击保持合法资格，但不保证打得过。缺药和0家底不能直接判死。
4. **新任务精力建立本身也是OPTION转换。** 下一任务确认后到其真实起点，任务日期Day1、精力建立100；这是显式新任务额度，不隐含过夜、不改健康。**不重复赠送新角色初始金属管、外套、工具或绷带**，只携带整备选定的真实物。
5. 返回/换任务编号不刷新尚未到期的药效、医疗日次数和已消耗标志行动额度；只有下一次真实且生还的日期推进才按规则更新。期限已结束的药效不复活，重开任务也不重复领次数。因此下一任务虽标Day1，已用完的医疗日次数在第一次真实过夜前可能仍不可再用；这项候选接续必须清楚提示并验证，不能承诺所有高感染角色都还能再救一次。
6. 本稿只给下一次同规则感染任务的接续见证，不新增第二世界。角色既有感染及暴露在第一次合法过夜以真实阶段结算；不能把“任务外”当治愈。未来其他世界的病程承接属于其内容边界，本稿不强制所有未来世界都有感染，也不宣称长期治愈经济已解决。

**0家底/缺药的具体结尾：** H0失败者HP1、仍流血，药食材料装备均0，则实物罚0；回中枢后仍为HP1的活人。可暂停或明确带伤出发，进入新任务本身不扣血；随后第一次需要流血检查的2E移动会令HP1→0，才发生实际死亡。该输入没有已证明的生还路线，不赠救命药、不把活人提前写死；已知致死风险必须预先可见。

**同状态但有家底：** 旧仓还有绷带1时罚则不收它；显式用药令HP1→2并止血，绷带0，下一任务首移动不因旧流血致死。既成感染仍保留。中枢旧药有真实价值，没有免费恢复。
