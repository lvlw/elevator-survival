## 3. 补给和解锁应怎样理解

默认可购不是默认赠送；0积分者没有凭空的购买力。购买产生真实物品，使用、携带和维修另按共同规则执行。没有远程购买、自动吃饭、自动补包或自动修装备。

医疗“世界专属解锁”首先描述中枢兑换资格的取得来源，不表示普通药只能在该世界出现，也不禁止通关前使用已拾到的合法药物。解锁、余额与实物拥有分开。当前讨论的是完成整项世界委托，不是退出医院一张地图即解锁。

物品的普通功能不因来源不同而改变：适配的中枢金属可用于合法当地安装，不为保住旧必跑搜索而加“本地产金属”隐藏门槛。需要真正专属对象的目标使用明确任务内容表达。

基础商店逐步降低重复搜集负担可以是成长收益；不要求所有路线都必须搜粮、做NPC交换或维修一次。仍需检查商品是否便宜到完全抹去场景中的合理资源选择。

## 4. 回归窗口必须保住

合法生还返回先保留真实身体并兑现合法所得。中枢静态不等于不能治疗／进食／维护；它只是不因停留或这些整备操作自动发生日期性损耗。

下一次出发读取全部整备后的真实状态，不回放返航时的旧感染与伤口。未发生的未来损耗不能反向改写上一任务成功。实际已发生HP0不能靠奖励、服务或重试撤销。

首次新角色入场与连续角色再次出发分开。任务末日截止是否已经结过某个周期必须单列说明；不得无条件双扣，也不得靠改名免除一个确实不同的周期。具体选择仍属Draft，至少提出一份可算的推荐，不因末日未批停下所有补给设计。
