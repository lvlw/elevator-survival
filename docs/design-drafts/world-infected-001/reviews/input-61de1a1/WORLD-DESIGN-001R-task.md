## 2. 必须完成的修订结果

### A. 去掉重新引入的每日区域门禁

删除主方案中的来源区只能通行、目标区日承诺、一次实质交互便锁住今日区域、跨区箭头必跨日等限制。并不取消精力、实际路径、权限、危险、未知信息和真正返回条件。

### B. 比较地图整合，而不是静默缩小世界

以输入v0.5的医院/酒店/供电所/物流/通信作为续写参照，对本次三地区整合做一份紧凑对照：保留/丢失的选择、人物与供电位置、A/C休整机会、必要回访及操作负担。比较在A修订后进行，不用旧日门禁证明五图不适合。
