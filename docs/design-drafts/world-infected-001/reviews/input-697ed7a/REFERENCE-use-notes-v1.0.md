## 本轮没有从参考中得到的规格

集合没有在上述相关入口提供可直接套用的统一全状态治疗报价、余额不足死亡时序或本游戏经验等级曲线。本轮必须由原创设计给出价格、范围、缺钱去向和时点，并以Draft标注，不用原著名义填空。

Owner所说“一口气回来，有资源就能恢复”的例子作为目标体验输入：合法生还后有实际付费修复机会，已死亡不可治疗。原作中的复活器具、免负分道具、支线兑换倍率、属性体系与本项目当前范围无自动映射。
