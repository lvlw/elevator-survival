## 1. Goal与一次完整交付

交付一个纯TypeScript的终局核心：只读资格／结果查询、受控正常返回／截止与真实死亡结果消费、唯一最小积分配置依赖、真实实例及既成历史处置，以及不可部分应用的完整TerminalPlan。详细设计、实现、正反例、真实跨模块组合、自查修订、文档与提交作为一个Goal完成。

## 2. 来源与权限边界

普通入口仅供只读查询及类型，不暴露任意close(outcome)、setCurrent、install、replace、commitExternalPlan或测试工厂。受控入口读取实际受控任务内容、当前现场及身体／物品事实；请求只表达H0交付、H0失败撤出、异地稳定截止等意图与绑定／revision，不能提交成功、死亡、费用、完整后态或supported证明。

真正五图任务件取得、设施安装和转运完成生产者目前未接。工程A可用绑定具体角色／委托／执行／目录／版本的受控内容测试夹具原生验证消费者；不能把测试事实工厂导出普通入口或注册第二任务。内容资格桥的可信边界、来源和完整前态绑定必须在工程详细设计与测试中明确，不以字段形状正确代替权限。

## 3. 输入、计划和原结果消费

严格读取完整输入、安全整数、身份／版本、声明全集、当前唯一活动任务、完整独立前态和可用上下文。当前已关闭、错执行、过期、伪造来源、原字段畸形或算术越界的请求语义拒绝，无外部副作用。

正常H0返回按完整真实资格分流：达标只成功交付，不达标才失败撤出；不自动结束或替换错误意图。指定样本须真实背包实例及正确定义／来源／执行，酒店访问不是门槛。Day7 H0走正常返回无夜，异地稳定截止先一次G1日结，仍活才期限失败。

## 5. 真实清算与历史

终局资格、任务关闭、钱包、实物处置及历史在纯完整提案中一并完成。失败收入0且只min(P,20)，普通合法携出和旧家底保留真实状态；重伤和少普通战利品不减完整成功奖励。携回样本成功交付／失败部分交付，携回未安装专件交回，权限失效，未携出物留不可访问历史。

普通物与任务件分类来自受控任务声明，不按显示名，也不把普通金属／布料一并没收。真实迁移保留实例、数量、ItemState、资源和原处分；已安装／交付／消费／毁失不改写。死亡只撤销当前可用资产与余额资格，不给新角色继承，不倒改旧成功或旧扣罚。

终局收据被动绑定身份、结果、周期、实际金额和处置引用；不建立第二份可变钱包、任务资格集合或事件日志仓库。输出必须足够让B做完整联合恢复，但不持久化由其他唯一事实可派生的副本。
