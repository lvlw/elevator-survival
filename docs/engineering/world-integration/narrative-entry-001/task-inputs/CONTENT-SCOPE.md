# 首批内容采用与节奏边界

## 批次身份

Owner已确认的故事主线不再反复征求：保护性停运、周衡是执行人、林岑提供等待者视角、玩家希望返回现实、最终由旧录音转向真实回应。

本包只把v0.2的序章与H01—H07作为首批DEV文案/交互实现输入。两份完整原稿逐字节随包保留；中后段提供上下文，不等于本次全部实装或规则批准。

本批真实首段可以在H07形成一次悬念收束，但原游戏继续可玩。不要新增“试玩到此为止”的人为锁门。

## 文本密度与外观

- 一个必经段最多连续三张短卡，之后交还操作。可立即显示全文；不以等待动画延长游戏。
- 新地点一般一条短观察。没有新信息就安静；回访不刷同一教程。
- 任务发布：简短且冷静的中枢装置感；普通旁白：有界、低干扰；现场工单：用现有风格做清晰可读的文书层。不是三个通用表单换标题。
- 复用现有获准中枢/前室/大厅/药房/工具素材。对话框、任务板、纸页和小图标可用现有CSS/内联SVG制作；本批不让图像生成或未知许可素材成为阻塞，也不新增第三方库。
- 不采用玩家v2、不补全人物立绘，不强制完整第一人称起身动画。短暂暗入/清晰可用；减动态版本同等信息、不损失操作。
- 所有可见效果都要在原入口运行，不交第二套剧情站点。原主视口旁侧边界可做必要局部修整，但不扩展多分辨率工作。

## 两个很小的明确文案调整

1. H06胜利后的“从他身边经过”改成不暗示额外移动的“你握着武器又等了片刻，才稍稍松开手。”
2. 无可信结果支撑的失败感慨不强行套模板；保留正式安全错误。不得凭台词担保所有失败都零效果或物品都还在原地。

除这类语义等价的修正、断句和可访问性短名外，不自行改写主矛盾、加隐藏惩罚、让中枢欺骗已公布条件或补一个新NPC。

## 回包后主线重点看什么

不是“增加了多少字”，而是：初见是否知道目的；动作是否变顺；到了H7是否自然想知道停运原因；主动选择路线是否仍成立；窗口/记录是否始终尊重真实状态。

中后段人物戏、高潮和结尾已有v0.2文本，首段实审后再复用这个窄接入能力。当前不额外开十轮准备，也不把整个新叙事系统无边界扩张。
