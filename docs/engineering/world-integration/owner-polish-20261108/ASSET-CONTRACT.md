# 展示资源接口

正式行动按钮、物品图、场景板和公开 NPC 近景从 `asset-slots.tsx` 取资源。默认由 `assets.ts` 的闭合映射提供；`ArtProvider` 供隔离候选传入同类型映射。图像键只存在于展示层。NPC 仍由真实公开互动绑定，场景仍由正式可见地点与状态匹配。图像加载、动画帧和失败不会进入命令输入或影响行动提交。

| 槽位 | 当前支持与规格 | 锚点与回退 |
| --- | --- | --- |
| 行动图标 | 实际接入。透明 SVG，24×24 viewBox，实测显示 16×16 CSS px。线条与轮廓留 2 px 安全边，方形 contain。 | 居中，动作短名由按钮语义提供。未知或失败保留文字与同一操作。 |
| 物品图 | 实际接入。沿用已采纳 PNG，透明边缘和可辨轮廓，contain 于固定格位；未知名称或损坏图使用原 SVG 占位。 | 居中，数量角标不依赖图像。实测快捷位空、满均 134.20×86 CSS px。 |
| 场景板 | 实际接入。沿用批准 PNG，以 cover 显示于当前舞台；横向源板允许按既有焦点裁切。主要识别物在中央安全区，文字与路线保持独立。 | `SceneArt.focal` 控制百分比锚点，药房等沿用 50%／42%。缺图显示舞台中性底。战斗实测板宽 800 CSS px。 |
| NPC／近景 | 实际接入。正式 PNG 仍默认。推荐透明 4:5 全身图，眼睛与职业识别物放在主体安全区，人物主体不碰画布边缘。候选 PNG 1122×1402 RGBA。 | 保留原近景框和姓名。未知人物无替代身份图，损坏退回中性框。A/B 试验框 320×420 CSS px。 |
| 敌人五阶段 | 维持原实际接入。原批准表逐张记录 PNG 画布尺寸与 placement，例如护工 1024×1280。仅按公开敌人键和公开阶段。 | 维持全组预载、过期拒绝、同帧中性回退和公开阶段文字。 |
| 动态素材 | NPC 槽位支持 GIF 与静态备用，生产映射本批仍为静态。候选为 512×640、2 帧、3 秒循环。设备 SVG 与 460ms 受击反馈只在离线候选。 | 场景切换或映射切换卸载旧元素。浏览器减少动态选择静态图，动图失败也回退静态。图像和动画均无写档或结算权。 |

同一 `src` 的加载失败由当前挂载持有。更换 `src` 按键重新挂载；旧元素的迟到事件不能改变新元素。第一批可换的类型是表中支持的映射，既有面板九切、声音和玩家资产没有扩张接口。
