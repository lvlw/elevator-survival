## 启动与隔离

在仓库根目录运行：

```text
npm run dev
```

使用 Vite 终端实际给出的端口，在独立测试浏览器 profile 中打开：

```text
http://localhost:<Viteport>/?dev-infected-world=1
```

不要原样输入尖括号占位；例如 Vite 报 5173，才使用 `http://localhost:5173/?dev-infected-world=1`。localhost 和 127.0.0.1、不同端口属于不同 origin，测试中请保持地址一致，避免误以为进度丢失。

本轮实际浏览器证据来自 Windows 上已安装 Edge 155、真实 localStorage 和 Web Locks；使用支持这些能力的安全浏览器环境。不支持时界面阻止写入，不降级为无锁保存。其他浏览器未运行的部分仍为 NOT RUN。

建议通过浏览器的 profile 管理建立独立测试 profile，不使用 Owner 日常 profile、医院存档或审计 runner 的临时 profile。不要复制／导入旧记录，也不需要打开控制台。关闭该测试 profile 的其他相同地址页，再进入本入口；普通隐身窗口的生命周期可能影响存档保留，不把它当长期进度保管承诺。

此入口仅 DEV 生效：无参数仍为原医院入口，旧 `?dev-ui-preview=1` 仍优先；两个参数同时出现不会创建两个 owner。生产构建忽略新 DEV 参数。新命名空间与旧医院槽隔离，不迁移、不扫描或删除旧槽。

## 首次操作

1. 明确选择一件实用工具和一项专长，再点击“确认创建”。创建后选择锁定，真实装备出现；不会自动出发。
2. 点击“进入封锁区”后开始探索。当前房间是中央舞台；“前往”只执行一条当前正式相邻边，已知地图只读，不提供瞬移或多步队列。
3. 在现场选择搜索／任务方案。需要工具、材料、数量、目标、分配或格位时会打开必要输入；编辑和取消不执行行动。普通已揭示整实例拾取可找未旋转首个合法格，特殊任务输出仍明确选位置。
4. 右侧切换背包／装备，两个快捷位常驻。背包与快捷物品用右键、菜单键或 Shift+F10 查看操作；键盘可达物品详情。缺图物品是中性占位，不是不存在或损坏。
5. “药食与维护”内可用正式药食、机械总池分配、外套／工具箱维护及充电。材料和伤势目标需明确选择；不会自动补快捷栏、合并或整理。
6. 战斗使用舞台行动条与正式快捷动作。携带面板可看，不代表开放战中整理或隔空药食；敌人只显示公开阶段、意图和相对顺序。
7. 主动返回、截止或关键留置等受保护操作按提示确认。取得任务物不是已交付；任务结果由正式终局表达。生还返回后无后继就是静态中枢；死亡不会复活或重接本委托。

此处不提供最优路线。首轮请自由决策并记录不清楚、繁琐或阻挡操作的位置；一次完成、合理撤退、主动分段和连续分段对照留到随后体验审查，不为追求通关要求手算或控制台命令。

## 如何理解反馈

- 病程仅公开当前粗档；最低档不等于未感染或未来安全，最高档不自动死亡。精确进度、潜藏暴露及未来周期答案不显示。
- “未证明必死”不等于安全；“未知”不等于可放心行动。隐藏医疗目标 Preview 仍可能未知，明确执行后才反馈正式结果。
- 搜索后的物品结果可收起重开；重开不会再次搜索或补发物资。行动记录只保留当前会话已公开变化，刷新不会伪造历史。
- 一般完整行动直接执行；必要输入并非额外通用确认。真正保护层居中，取消不执行。

## 保存、占用与停止反馈

“操作已生效，尚未保存”表示最新内存仍保留。优先使用“重试保存”；它只保存最新完整状态，不重复战斗、随机、用药、维护或结算。**刷新只能恢复最后成功 checkpoint**，可能丢失尚未持久化进度；不要反复点击原动作当作保存重试。

另一页面占用时，本页不创建身份、发物或写入；关闭占用页后明确“重新取得独占”。导航、失锁或 BFCache 恢复后旧选择不可继续提交，重新取得独占须冷恢复，不接回失锁旧内存。

坏档、读取异常、孤立预留或投影问题会阻止相关操作；没有 Reset、清档、迁移、自动 repair 或重新发初配按钮。不要手动删记录来掩盖故障。出现程序异常、控件不可达、保存持续失败、无故丢失物品、旧选择意外执行或遮挡时停止操作，保留页面并反馈当前地点、刚才的点击、文案、视口及截图；不必上传原始存档、profile 或隐藏内部数据。
