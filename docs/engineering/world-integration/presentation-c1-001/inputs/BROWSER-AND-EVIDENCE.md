# 浏览器与证据分层

## 使用什么

使用当前可用的实际浏览器能力（现有应用内浏览器或已连接的测试浏览器），实际打开本地构建/DEV入口 `?dev-infected-world=1`。不得以HTML源码、人工拼装示意页、测试canvas截图或静态设计原型代替生产React页面。

允许为本任务启动/停止你自己创建的回环测试服务和独立测试profile，端口取实际空闲值。禁止打开远程隧道、云服务器、改Wiki/防火墙/证书、安装新依赖/扩展或操作Owner日常profile。不要物理断网、清理Owner存档，坏档也不能用自动Reset掩盖。

## 必须分开记录的层次

纯消费假时钟；真实P/R/S+controller；真实React DOM；真实浏览器；Owner人工体验，是五层不同证据。使用TEST-only故障端口或合法checkpoint的浏览器用例必须说清注入位置，不能声称验证了操作系统真实配额耗尽或自然首玩路径。

## 原生检查重点

至少实际验证：可见当前三敌之一的A名称；真实按钮提交一次后反馈可见及消退；下一动作能正常执行、不会等动画；保存失败已生效/重试不回放；冷刷新无历史反馈；键盘跳过/减少动态不执行动作；页面离开或同源占用后的旧控件不可继续；终局即时切换不保留可用战斗场次。

三敌/六动作/五停点的全矩阵以自动原生链为主，浏览器选代表流程并明确覆盖，禁止把一个浏览器示例说成全部组合都人工验证。原生零伤等不达状态不造新参数。

推荐实际视口1920×1080、1366×768、1280×720与390×844压力档，核对舞台/行动/保存提示/跳过/本地减少动态可达，无新增整页横向溢出和必要控件遮挡。保持真实6×4背包。真实125%/150%浏览器缩放能在独立测试profile执行则补测；只有CSS视口模拟时写NOT VERIFIED，不让Owner为本批逐项改配置。

至少有默认动态与浏览器实际 `prefers-reduced-motion` 生效的观察；模拟OS偏好须标“浏览器媒体仿真”，不得写真实系统设置。设置无法读取/改变时保留局限。

截图应为真实浏览器原尺寸像素，注明CSS视口/DPR、URL路径/任务构建SHA、前后动作、是否测试夹具、时间点。抓到短反馈可用自动等待/截图，不得通过改生产时长、改样式、重绘或手动拼接制造效果。截图含环境浮标时保留并记录，不修图遮盖。

交付约4—7张必要代表图即可：正常反馈、保存失败、减少动态/键盘、真实终局、窄屏等，不重新打包旧177张设计图。浏览器日志/DOM计数和来源记录提供可复核细节；不是靠静态截图单独证明恰好一次。

本轮浏览器完成也只关闭C1声明覆盖，不关闭完整美术、跨全部平台、Owner首玩/分段九组合或公开发布。
