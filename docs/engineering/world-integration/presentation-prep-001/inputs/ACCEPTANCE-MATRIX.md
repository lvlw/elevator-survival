## 证据要求
- 测试名称对应具体断言和真实入口，不用“全通过”替代定位。
- 在真实query中看到新字段才算接线；helper单测不能代替。
- 使用明确TEST合法边界状态时写清不是从read-null走完整路线；至少三敌首入使用正式生产者。
- 非干涉不得删除整个actions、warnings或诊断后再比较。允许句柄一一对应归一化，不允许消除有意义公开差异。
- 旧24字段合同不改；新增字段自己的精确键检查放新测试。
- 反例运行前先确认触达注入点；环境/超时/类型错误保留但不计语义检出。
- 记录新增/替换/删除/净增测试，组合测试包含旧项不累加为新增。
- B测试观察只能证明来源存在或缺失，不能标B生产事件系统已完成。
- 没执行真实浏览器/Owner试玩就NOT RUN；本批不是视觉布局任务，通常无需新截图或独占浏览器。

## 已知不得误解的阶段事实
selectEnemyHealthPhase可能在正HP时返回incapacitated。
测试有五种公开phase并不意味着每种敌人都存在合法的活战斗原生状态覆盖五相同区间。
对实际不可达组合标记原因，并用纯映射完整性检查覆盖资源规格；不得篡改生产参数。
