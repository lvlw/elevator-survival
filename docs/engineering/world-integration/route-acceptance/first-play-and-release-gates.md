# 首玩与发布 Gate（E03-A 后仍未关闭）

工程和 headless 路线可达不等于首次体验通过。

1. 当前候选[完整安全查询工程](next-engineering-contract-draft-v1.0.md)必须先技术审定、实现与准确 SHA 实审；raw getState、包含 seed 的 item selector 和 execution 的 wound selector 不能直接用于普通 UI。
2. 低资产 UI 只消费正式安全查询、最新命令资格与相对风险，不能成为第二规则／库存／敌人 owner。
3. 浏览器存储需要独立于候选的真实启动材料持久化、保存失败反馈与严格冷恢复；headless memory port 不是浏览器验收。
4. 多标签唯一 writer／冲突处理另有实际工程和测试，不拿当前 domain WeakMap 冒充跨页面锁。
5. O3 旧医院入口／旧槽路由、备份／清理、冲突及回滚发布安排仍 OPEN；本批未决定、未迁移、未清档。
6. Owner 原生玩家信息下首玩、九工具／专长组合与分段突破比较仍 OPEN / NOT RUN。要观察重复赶路、治疗与资源竞争负担；自动测试和内部 HP ledger 不替代体验。
7. 发布前依赖告警、大 bundle 与 Actions 运行时提示另派维护；本批只读调查不升级、不改 CI，也不据 dev-only 就宣称安全。

当前只有一份真实委托；关闭后生还者静态中枢，没有自动发下一委托、免费治疗或续做入口。地图美术、音频、商城、未来专长改选与完整长期内容不由此验收自动批准。
