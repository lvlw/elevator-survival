## 原生验证安排（Codex执行，不叫Owner替作者验收）

先用正常空TEST origin从Setup走到药房与至少首场战斗。其他敌人/异常可由现有生产者和严格codec产生合法TEST checkpoint补充，但标明来源，不直接写HP/背包来摆图。至少有一条跨搜索、拾取、实物操作、参数、战斗、保存/恢复的真实连续链。

五桌面档都实际观察核心几何；原图重点覆盖药房（未搜/有物/取空）、背包/详情/参数、三敌战斗以及保存或保护层。建议8—12张原图，以证据充分为准，不设置靠堆截图凑数的硬数量。无像素全幅证据的档位不得标视觉PASS；当截图工具不工作时先记录具体问题，尝试当前已授权的另一有效通道一次，禁止重复无效操作或修图补边。

C16历史缺口不自动关闭。媒体true、真实zoom、390只有实际完成才更新；模拟视口不等于缩放。没有该能力不会冻结M1/M2，但报告不得说全部浏览器验收完成。Owner体验继续NOT RUN。
