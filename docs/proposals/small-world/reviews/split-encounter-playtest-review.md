# 分段突破：Owner实际试玩复审项

> 状态：OPEN / NOT RUN。当前规则允许分段突破；体验未通过。本文件是验证安排，不新增玩法规则。
> 规则依据：[DEC-048](../../../05-design-decisions.md)；确认来源：[Owner确认记录](../owner-confirmations.md)。

## 比较范围

| 对照 | 观察问题 |
|---|---|
| 准备充分，一次完成 | 完整节奏与成本是否合理，是否被人为做成吃亏选项？ |
| 遭遇不利，合理撤退再来 | 之前投入是否有成果感；保留的危险意图是否可理解；再次出发是否在执行新计划？ |
| 本可继续，却主动分段 | 每次探索蓄力额度、新日工时和恢复是否让分段普遍压倒其他选择？必须计入日期、往返、食物和放弃的其他访问。 |
| 连续多次分段 | 是否退化为反复进出、赶路、打开整备界面，冲淡紧张感？ |

先用正常玩家界面自由试玩，再做定向对照。普通信息不公开内部敌人HP、raw CTB、完整未来循环或未发现来源。不得把精确脚本操作当作首玩者默认知识。

记录日期、真实资源/工时消耗、最低生命、公开伤势/暴露、敌人公开阶段、重复访问/操作及Owner感受。规则执行正确、信息可理解、体验有趣分开报告，不预设通过率或“最多允许撤退几次”。

发现问题先区分信息、时序/数值、日期/资源预算、操作负担与生命周期本身。需要修改保留生命、下一意图、再接战或撤退语义时重新讨论；不可由Codex自行关闭复审或擅自修改规则。
