# 医院世界 · 视觉候选审看

双击同目录的 [REVIEW.html](REVIEW.html) 即可离线打开。保留上一级的 assets 文件夹。该页只持有临时展示样本，刷新回到默认候选状态。工程分支的 React 资源替换证据独立于这套候选页面。

1. 探索页切换流血，观察警示是否与生命条相邻。填充和清空快捷位 2。切到流血后打开「药食与维护」试演止血，观察伤口标记和生命值保留。查看图标 A/B。
2. 战斗页点击「攻击」播放一次受击，观察公开阶段文字与行动条。当前使用既有受伤护工贴图和代码绘制的玩家背身示意。
3. 人物页点击「对照 A / B」比较林岑。A 是现有正式图的网页预览转码，B 保留她的工作夹克、束发、靴子，调整剪裁、站姿、妆发与眼神。人物设定和实际交换条件以正式内容为准。
4. 死亡页查看物品处置，再进入新尝试设置。完成两个选择后进入确认，先取消一次，再确认离线流程样本。

关闭页面右上角的「播放动态样片」或系统减少动态可回到静态图。候选 GIF 缺图回退到同一立绘，设备动画缺图回退常亮图。候选 GIF 的两帧有轻微生成纹理差异，当前作为节奏样片，未做连续呼吸或全身动作。下一稿可固定面部对位并补中间眼睑帧。

使用独立的 Edge 157 测试 profile 直接打开 file: 页面，DPR 1。1440×900 和 1280×720 均完成上述候选流程，无页面错误和横向溢出。快捷位分别为 113×56 和 98×56 CSS px。动画测量时分别采样 GIF 与设备元素，GIF 出现不同实测画面，设备灯环测到 4 个画面。测试在两档各验证关闭动效、系统减少动态、受控缺 GIF 回退、换角确认与取消。上述是离线候选的浏览器证据。

浏览器读数和原图哈希见 candidate-browser.json。图像原件、转码及 GIF 哈希见 assets/media-receipt.json。源图生成通道为内置 image_gen 图像编辑，实际底层图像模型版本无可核验回执。生成提示保留既有林岑身份和工作服，成人造型与表情仅作视觉审看。闭眼图为同一候选的闭眼微调。
