# Content

存放版本化内容配置，不保存可变 Run 状态。

- 医院 `v0.1` 配置位于 `hospital-v0.1/`。
- 内容配置先通过核心 Zod 契约校验，再递归冻结。
- 注册表对未知版本明确失败，绝不回退到最新版本。
- 后续规则版本应追加注册，不覆盖旧版本对象。
- 医院节点图属于版本化内容，稳定节点ID和边ID不得因展示文案变化而改变。
- 静态图只保存潜在连接；本次探索的运行时通行状态不写入静态图定义。
- 新医院图版本必须新增版本化内容入口，不能静默覆盖旧版本图对象。
- 医院物品物理目录位于 `hospital-v0.1/items/`；稳定物品ID不随展示名称变化。
- 当前物品目录只保存尺寸、重量、旋转和堆叠等物理库存属性，不包含随机品质或词缀。
- 攻击、医疗、维护、装备资格及其他行为由后续独立能力目录通过相同稳定物品ID关联。
- 新规则版本应增加对应的新物品目录，不得静默覆盖旧版本定义。
- 医院物品资源档案位于 `hospital-v0.1/items/`，通过稳定物品ID与物理目录关联；资源上限来自同版本规则配置。
- 物理库存属性与状态资源分属独立目录；新规则版本不得静默覆盖旧资源档案。
- 医院18件正式物品均具有明确资源档案；消防斧依照 DEC-039 使用最大值2的耐久资源。
- 医院装备资格目录位于 `hospital-v0.1/items/`，通过稳定物品ID关联物理目录，包含2项武器、1项防具、3项实用装备和12项不可装备物品。
- 装备资格与状态资源彼此独立；新规则版本不得静默覆盖旧资格目录。
- 医院快捷栏资格目录位于 `hospital-v0.1/items/`，通过稳定物品ID关联物理目录；当前7项可进入、11项不可进入。
- 快捷栏资格、装备资格和物品资源档案相互独立，资格本身不表达具体使用效果或使用上下文。
- 医院三个主要搜索定义位于 `hospital-v0.1/search/`，分别配置固定物品、零次或一次加权抽取，以及固定情报ID。
- 主要搜索掉落使用独立的确定性随机子流；手电筒及其电量不属于掉落物化输入，不改变正式物品结果或固定情报ID。
- 医院18项搜索照明资格档案位于 `hospital-v0.1/items/`；只有 `utility_flashlight` 是低照明主要搜索提供者，其余17项均不是提供者。
- 医院搜索命令显式选择有灯20或无灯30；照明成本1来自同版本规则配置，搜索揭示结果仍留在节点。
