# Core

纯 TypeScript 规则、状态转移、Effect、确定性随机与结算逻辑的边界。

- 配置契约和运行时校验属于核心，具体医院配置不属于核心。
- 最小 Run 身份在创建时绑定已注册的规则版本。
- 核心不依赖 React、React DOM、Zustand、DOM 或浏览器 API。
- 本阶段仍不实现玩家移动状态、开门、战斗、库存、维修或日结算规则。

## 确定性随机

`src/core/random` 提供版本化的计数器式确定性随机基础。结果由种子、随机算法版本、命名子流和抽取序号共同决定，各子流彼此隔离。

- 禁止使用 `Math` 对象的 `random()` 或任何时间、系统随机源。
- 算法输出由黄金测试锁定。
- 改变既有随机序列必须增加算法版本，不能静默修改旧版本。
- 规则版本决定游戏参数；随机算法版本决定种子与抽取序号如何映射为随机结果。

## 场景时间事务

`src/core/scene` 负责正时间非战斗场景行动的通用事务。具体行动先由调用方计算主要效果和行动完成后的预计返程时间，通用事务再统一处理时间扣除、超时债务、行动后流血、死亡检查和紧急返程。

- 节点、负载、伤势与路线规则由其他模块计算，不在场景事务中推断。
- 预览和正式结算共用同一权威计算逻辑。
- 输入快照不会被修改，事务输出及其嵌套快照在运行时冻结。
- 场景核心不依赖医院内容、随机模块或 UI。

## 负载与移动时间

`src/core/load` 负责根据调用方提供的背包总重量判定负载等级，并计算节点移动和返程共用的时间修正。

- 物品重量求和和背包格子布局不属于本模块。
- 多个百分比倍率使用整数比例相乘，只在最终结果处向上取整一次。
- 轻微挫伤增加移动与返程时间；镇痛生效时暂时抑制该修正，但不移除伤势。
- 本模块只查询三种可携带负载等级的逃跑基础 CTB，不实现逃跑行动或伤口加时。
- 场景事务只接收已经计算完成的返程时间，不反向依赖负载模块。

## 场景节点图与返程路径

`src/core/scene-graph` 负责不可变静态拓扑、调用方显式提供的可通行边，以及采用稳定平局规则的确定性路径。

- 静态图只描述节点和潜在连接；工具、门禁卡、事件及开门资格由其他模块处理。
- 返回路线先合计所选路线的基础时间，再调用负载模块统一应用负载与伤势倍率并最终取整。
- 场景事务只接收最终预计返程时间，不读取节点图或重复应用时间修正。
- 核心图模块不依赖医院内容、随机源、全局可变状态或浏览器能力。
