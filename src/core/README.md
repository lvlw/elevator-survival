# Core

纯 TypeScript 规则、状态转移、Effect、确定性随机与结算逻辑的边界。

- 配置契约和运行时校验属于核心，具体医院配置不属于核心。
- 最小 Run 身份在创建时绑定已注册的规则版本。
- 核心不依赖 React、React DOM、Zustand、DOM 或浏览器 API。
- 本阶段仍不实现场景、战斗、库存、维修或日结算规则。

## 确定性随机

`src/core/random` 提供版本化的计数器式确定性随机基础。结果由种子、随机算法版本、命名子流和抽取序号共同决定，各子流彼此隔离。

- 禁止使用 `Math` 对象的 `random()` 或任何时间、系统随机源。
- 算法输出由黄金测试锁定。
- 改变既有随机序列必须增加算法版本，不能静默修改旧版本。
- 规则版本决定游戏参数；随机算法版本决定种子与抽取序号如何映射为随机结果。
